# 11th Grade Physics — Core Mechanics

A study project covering the five foundational mechanics topics of an 11th
grade (Physics 1 / algebra-based) course. Each unit has key concepts,
Cornell notes, an interactive "most missed questions" quiz, practice
problems and real-world applications, a one-page study guide, SAT/ACT-style
practice, and a mastery checklist.

## Units

| Unit | Topic |
|---|---|
| 1 | [Kinematics](11th-grade-physics/01-kinematics/README.html) — distance/displacement, velocity, acceleration, graphs, the four kinematic equations |
| 2 | [Projectile Motion](11th-grade-physics/02-projectile-motion/README.html) — 2D motion under gravity, range, max height, time of flight |
| 3 | [Newton's Laws](11th-grade-physics/03-newtons-laws/README.html) — inertia, Fnet=ma, action-reaction, friction, free-body diagrams |
| 4 | [Momentum](11th-grade-physics/04-momentum/README.html) — momentum, impulse, conservation of momentum, collisions |
| 5 | [Work & Energy](11th-grade-physics/05-work-and-energy/README.html) — work, kinetic/potential energy, the work-energy theorem, power |

## How to Use This

1. Work through the units in order — each builds on the last (Kinematics →
   Projectile Motion → Newton's Laws → Momentum → Work & Energy).
2. In each unit, read Key Concepts, fill out Cornell Notes, then take the
   Interactive Quiz *without notes* — it's diagnostic, so wrong answers tell
   you exactly what to re-study.
3. Do the practice problems and SAT/ACT practice, then self-assess with the
   Assessment Checklist before moving on.
4. After Unit 5, take the cumulative review and log your results in the
   Progress Tracker.
