# Cornell Notes — Kinematics

> **How to use:** Cover the "Notes" column and try to answer each cue from memory first. Write your own summary at the bottom *before* checking the one provided — comparing your version to a model summary teaches you more than reading the model alone.

| Cue / Question | Notes |
|---|---|
| What is displacement? | Vector; change in position, $\Delta x = x_f - x_i$. Direction matters — can be negative. Straight-line distance from start to end point, regardless of path taken. |
| How is displacement different from distance? | Distance is a scalar — total length of path traveled, always positive, never decreases. Displacement can be zero even if distance traveled is large (e.g., a runner who returns to the starting line). |
| What's the difference between average and instantaneous velocity? | Average velocity = total displacement ÷ total time ($\bar v = \Delta x/\Delta t$) — a single number over an interval. Instantaneous velocity = velocity at one specific moment = slope of the tangent line to the position-time graph at that point. |
| What is acceleration, formally? | Rate of change of *velocity*, not speed: $a = \Delta v / \Delta t$. Units: m/s². Can be caused by a change in speed, direction, or both. |
| Can something accelerate while moving at constant speed? | Yes — if direction is changing (e.g., circular motion). Velocity is a vector; changing direction changes velocity even if magnitude (speed) is constant. (Deeper treatment in circular motion, beyond this unit.) |
| When is acceleration "positive" vs "negative"? | Depends entirely on the chosen positive direction — NOT on whether the object is speeding up or slowing down. Positive acceleration + positive velocity = speeding up. Positive acceleration + negative velocity = slowing down. |
| List the 4 kinematic equations and when each is used (constant $a$ only). | $v=v_0+at$ (no position); $x=x_0+v_0t+\tfrac12at^2$ (no final velocity); $v^2=v_0^2+2a\Delta x$ (no time); $x=x_0+\tfrac12(v_0+v)t$ (no acceleration). Pick the one missing the variable you don't know and don't need. |
| Position-time graph: what does slope mean? What does curvature mean? | Slope = velocity. A straight line = constant velocity. A curve = changing velocity (acceleration). Concave up = positive (increasing) acceleration in that graph's sign convention. |
| Velocity-time graph: what does slope mean? What does area mean? | Slope = acceleration. Area between the curve and the time axis = displacement (signed — area below axis counts as negative displacement). |
| Free fall: what is the acceleration at the very top of a vertical throw? | Still $-g$ (9.8 m/s² downward) — gravity never turns off. Velocity is momentarily zero at the top, but acceleration is not. This is the single most common conceptual error in this unit. |
| Free fall: is time up equal to time down for a thrown object (no air resistance)? | Yes, by symmetry, if it lands at the same height it was launched from. Speed at a given height is also the same going up and coming down (magnitude only — direction is opposite). |

## Summary (write this in your own words first)

Kinematics describes *how* something moves using position, velocity, and acceleration, treating velocity and acceleration as vectors whose sign depends on a convention you choose at the start of a problem. The four kinematic equations only apply when acceleration is constant, and each one omits exactly one variable — so problem-solving is mostly about identifying which equation omits the variable you're not given and don't need. Graphically, each quantity is the slope of the graph above it (position → velocity → acceleration) and the area under the graph below it (acceleration → velocity → position). Free fall is the most common application: constant acceleration $g$, downward, even at the peak of the motion where velocity is momentarily zero.
