# Topic 1: Kinematics — Cornell Notes

## Learning Objectives
- Distinguish distance from displacement, and speed from velocity.
- Define acceleration and identify its sign relative to velocity's sign.
- Read and construct position–time, velocity–time, and acceleration–time graphs.
- Select and apply the correct kinematic equation for a given problem.
- Analyze free-fall motion, including objects thrown upward.
- Solve multi-stage motion problems.

---

| Cues / Questions | Notes |
|---|---|
| What's the difference between **distance** and **displacement**? | Distance = total path length traveled (scalar, always positive). Displacement = straight-line change in position from start to end, `Δx = x_f − x_i` (vector, can be negative or zero even if distance traveled is large — e.g., a round trip has displacement 0). |
| What's the difference between **speed** and **velocity**? | Speed = distance / time (scalar). Velocity = displacement / time (vector, has direction). Average speed ≠ average velocity's magnitude unless motion is one-directional. |
| What is **acceleration**? | Rate of change of velocity: `a = Δv / Δt`. Units: m/s². Acceleration is a vector — its sign only tells you the *direction* of the acceleration, not whether the object is speeding up or slowing down. |
| When is an object **speeding up** vs **slowing down**? | Compare the signs of velocity and acceleration. Same sign (both + or both −) → speeding up. Opposite signs → slowing down. Velocity = 0 at an instant does **not** mean acceleration = 0. |
| What are the **four kinematic equations** (constant acceleration only)? | 1) `v = v₀ + at` 2) `Δx = v₀t + ½at²` 3) `v² = v₀² + 2aΔx` 4) `Δx = ½(v₀ + v)t` — each equation omits one of the five variables (`x, v₀, v, a, t`); pick the equation that omits the variable you don't know and aren't solving for. |
| How do you read a **position–time graph**? | Slope = velocity. Steeper slope = faster. Flat line = at rest. Curved line = accelerating. Negative slope = moving in the negative direction. |
| How do you read a **velocity–time graph**? | Slope = acceleration. Area under the curve = displacement. A horizontal line above zero = constant positive velocity. A line crossing zero = the object reverses direction. |
| How do you read an **acceleration–time graph**? | Area under the curve = change in velocity, `Δv`. A flat non-zero line = constant (uniform) acceleration. |
| What is **free fall**? | Motion under gravity alone, `a = −g = −9.8 m/s²` (taking up as positive). Applies whether the object is dropped, thrown down, or thrown up — the acceleration is always `−g`, even at the peak of an upward throw where `v = 0`. |
| What is **relative motion**? | Velocities add/subtract when switching reference frames: `v_A relative to C = v_A relative to B + v_B relative to C`. Direction matters — define a positive direction first. |
| How do you handle a **multi-stage problem** (e.g., speeds up, then constant, then slows down)? | Break it into segments with constant acceleration in each. The final velocity/position of one segment is the initial velocity/position of the next. Never apply one kinematic equation across a change in acceleration. |

## Key Vocabulary
**Scalar** (magnitude only) vs. **Vector** (magnitude + direction) · **Instantaneous velocity** (velocity at one instant, = slope of tangent line on x-t graph) · **Uniform acceleration** (constant a) · **Terminal velocity** (not reached in free fall without air resistance — a idealization used in this unit)

## Summary
Kinematics describes *how* something moves without asking *why*. The core
skill is keeping displacement, velocity, and acceleration straight as
vectors — tracking sign consistently — and matching the right one of the
four kinematic equations to the variables a problem gives you. Graphs are
just another representation of the same three quantities: slope and area
are the tools that move you between position, velocity, and acceleration.
