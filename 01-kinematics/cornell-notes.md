## Page 1: Describing Motion

| Cue | Notes |
|---|---|
| What's the difference between distance and displacement? | Distance = total path length (scalar). Displacement = straight-line change from start to end position (vector). Displacement can be zero even if distance isn't (e.g., a round trip). |
| Speed vs. velocity? | Speed = distance / time (scalar). Velocity = displacement / time (vector, has direction). |
| Average vs. instantaneous velocity? | Average velocity = total displacement / total time. Instantaneous velocity = velocity at one specific moment (slope of the tangent line on a position-time graph at that point). |
| What is acceleration? | Rate of change of velocity: a = Δv / Δt. Units: m/s². Can result from speeding up, slowing down, OR changing direction. |
| Sign convention | Pick one direction as positive at the start of a problem and stay consistent for position, velocity, AND acceleration. |

## Page 2: Motion Graphs

| Cue | Notes |
|---|---|
| Position-time graph: slope = ? | Velocity. Straight line = constant velocity. Curve = changing velocity (acceleration). |
| Velocity-time graph: slope = ? | Acceleration. |
| Velocity-time graph: area under curve = ? | Displacement (Δx). |
| Acceleration-time graph: area under curve = ? | Change in velocity (Δv). |
| Common trap | Slope of position-time ≠ slope of velocity-time. Don't mix up "steepness" across different graph types. |

## Page 3: The Kinematic Equations (constant acceleration only)

| Cue | Notes |
|---|---|
| v = v₀ + at | Missing: displacement x. Use when you don't need/have position info. |
| x = v₀t + ½at² | Missing: final velocity v. |
| v² = v₀² + 2aΔx | Missing: time t. |
| x = ½(v₀ + v)t | Missing: acceleration a. |
| How to choose an equation | List your known variables (v₀, v, a, x, t) — pick the equation missing the ONE variable you don't have and aren't solving for. |
| Free fall | a = g ≈ 9.8 m/s² downward, for any object with no air resistance, regardless of mass. Velocity at the peak of a throw is momentarily 0, but acceleration is still g downward. |
