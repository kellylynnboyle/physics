| Cues / Questions | Notes |
|---|---|
| What's the difference between distance and displacement? | Distance = total path length traveled (scalar, always ≥ 0). Displacement = straight-line change in position, with direction (vector). Example: walk 3 m east then 3 m west → distance = 6 m, displacement = 0 m. |
| What's the difference between speed and velocity? | Speed = distance / time (scalar). Velocity = displacement / time (vector). Average speed can be positive even when average velocity is zero. |
| How is acceleration defined? | `a = Δv / Δt` — the rate of change of **velocity**, not speed. An object can accelerate by speeding up, slowing down, *or changing direction*. |
| What does the slope of a position-time graph tell you? | Slope = velocity. Steeper slope = faster. A flat (horizontal) line = at rest. A curved line = changing velocity (acceleration). |
| What does the slope of a velocity-time graph tell you? | Slope = acceleration. A horizontal line = constant velocity (zero acceleration). |
| What does the area under a velocity-time graph tell you? | Area = displacement over that time interval. Area below the axis counts as negative displacement. |
| List the 4 kinematic equations. When can you use them? | 1) `v = v₀ + at`  2) `Δx = v₀t + ½at²`  3) `v² = v₀² + 2aΔx`  4) `Δx = ((v₀+v)/2)t`. **Only valid when acceleration is constant.** Each equation is missing one of the 5 variables (v₀, v, a, t, Δx) — pick the equation missing the variable you don't have/need. |
| What's special about free fall? | Constant acceleration `g = 9.8 m/s²` directed downward (toward Earth). Air resistance ignored. At the top of a vertical throw, velocity = 0 but acceleration is still `-g`. |
| How do you set up a sign convention? | Pick a positive direction (commonly "up" or "the direction of initial motion") *before* solving. Apply it consistently to velocity, acceleration, and displacement in that problem. |
| What is relative motion (1-D)? | Velocities add/subtract depending on reference frame. E.g., a passenger walking forward at 1 m/s on a train moving at 20 m/s has a ground-frame velocity of 21 m/s. |

## Quick Reference — Kinematic Equations

| Equation | Missing Variable |
|---|---|
| `v = v₀ + at` | `Δx` |
| `Δx = v₀t + ½at²` | `v` |
| `v² = v₀² + 2aΔx` | `t` |
| `Δx = ((v₀ + v)/2)t` | `a` |

## Common Mistakes to Flag in Your Own Work

- [ ] Did I mix up distance/displacement or speed/velocity in my answer?
- [ ] Did I confuse the slope and the area on a graph?
- [ ] Did I forget that deceleration is just "acceleration opposite to velocity," not always negative `a`?
- [ ] Did I use `g = 9.8 m/s²` with the correct sign for my chosen positive direction?
- [ ] Did I check that acceleration is actually constant before using the kinematic equations?
