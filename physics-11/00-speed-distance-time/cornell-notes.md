## Topic 1: Distance vs. Displacement

### Key Vocabulary (from notes)

| Term | Definition |
|---|---|
| **Position** | Location of an object relative to a reference point or origin |
| **Reference point / origin** | A place or object used for comparison; a coordinate system tells you where the zero point is |
| **Distance** | Total length of the *actual path* traveled between two points |
| **Displacement** | Length of the *straight line* between the starting and ending points, **including direction** |
| $x_0$ | Initial position |
| $x$ | Final position |
| $\Delta x = x - x_0$ | Displacement |
| $t$ (or $\Delta t$) | Time interval |

### Apprentice Level — Cue Column → Notes

| Cue | Notes |
|---|---|
| Is distance dependent or independent of the path taken? | |
| Is displacement dependent or independent of the path taken? | |
| Which of these is a **vector** and which is a **scalar**: position, distance, displacement? | |
| What does the sign (+/-) of a displacement tell you? | |
| If you walk 6 m forward then run 10 m back, what is the total **distance**? | |
| If you walk 6 m forward then run 10 m back, what is the total **displacement**? | |

### Master Level — Cue Column → Notes

| Cue | Notes |
|---|---|
| **Class example:** A person starts on the 2 m mark, walks to the 8 m mark, then runs back to the -2 m mark. Find: initial position, position at end of walk, position at end of run. | |
| From the same example — find the distance traveled during the walk, during the run, and the **total distance**. | |
| From the same example — find the displacement for the walk, the run, and the **total displacement**. | |
| Why is the total distance (16 m) so much larger than the magnitude of the total displacement (4 m) in this example? | |
| For a multi-leg path with a *direction change* in the middle, why can't you just add up the individual displacement magnitudes to get the total? | |
| Vectors from class: Displacement, Velocity, Acceleration, Momentum, Force. Scalars from class: Distance, Speed, Time, Mass, Energy. Why does this list matter when solving a problem? | |

**Answer check (class example, for self-grading only — cover before you try it):**
> Position: $x_0 = 2$ m, end of walk $= 8$ m, end of run $= -2$ m.
> Distance: walk $= 6$ m, run $= 10$ m, **total $= 16$ m**.
> Displacement: walk $= +6$ m (forward), run $= -10$ m (back), **total $= -4$ m (4 m back)**.

## Topic 2: Speed-Distance-Time

### Key Vocabulary (from notes)

| Term | Definition |
|---|---|
| **Speed** | How fast an object is moving — a number only, no direction (scalar) |
| **Average velocity** | Displacement over a (longer) time interval, in a direction |
| **Instantaneous velocity** | Displacement during a tiny instant of time, in a direction |
| $v = \dfrac{\Delta x}{t}$ | Average velocity formula |
| Units | Displacement/Distance = meter (m); Time = second (s); Velocity/Speed = m/s |
