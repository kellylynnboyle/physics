| Cues / Questions | Notes |
|---|---|
| What does Newton's First Law really say? | An object keeps its current velocity (including zero) unless a net force acts on it. "At rest or in motion" both count — constant velocity in a straight line means zero net force, same as being at rest. Motion does NOT require a force; changing motion does. |
| What does "equilibrium" mean? | Net force = 0. This does not mean the object is stationary — a hockey puck sliding at constant velocity on frictionless ice is in equilibrium, just like a book sitting on a table. |
| What does Newton's Second Law say, precisely? | ΣF = ma, a vector equation. Add up all force *components* along each axis separately (ΣFx = max, ΣFy = may). Acceleration points the same direction as the net force — not necessarily the same direction as the current velocity. |
| Does more force always mean more acceleration? | Only for fixed mass: a = F/m. For the SAME force, more mass means LESS acceleration. A heavier object does not accelerate faster than a lighter one under an identical applied force — that's backwards. |
| What about "heavier objects fall faster"? | False in free fall specifically: with no air resistance, a = g for every mass, because F = mg and a = F/m = mg/m = g — the mass cancels. Don't confuse this special case with the general F = ma relationship above. |
| What does Newton's Third Law say, precisely? | For every force object A exerts on object B, object B exerts an equal-magnitude, opposite-direction force of the SAME TYPE back on object A. The two forces act on DIFFERENT objects, so they never cancel each other out. |
| Table pushes up on a book — what's the Third Law pair? | The reaction is "the book pushes DOWN on the table" (same type — normal force — same magnitude, opposite direction, other object). It is NOT "gravity pulls the book down" — that's a different force entirely, and it acts on the same object (the book), so it's a balanced pair, not a Third Law pair. |
| Mass vs. weight — what's the difference? | Mass (kg) is a scalar measure of inertia; it doesn't change with location. Weight (N) is a force: weight = mg. Same object weighs less on the Moon (smaller g) but has the same mass everywhere. |
| Is normal force always equal to mg? | No. Only on a flat, level surface with no other vertical forces. In an elevator accelerating upward, N > mg. Accelerating downward, N < mg. On an incline, N = mg cosθ. With an added downward push, N increases; with an upward pull, N decreases. |
| Static vs. kinetic friction — what's the trap? | Kinetic friction (while sliding) is fixed: f = μₖN. Static friction (before sliding) is NOT fixed — it equals whatever is needed to prevent motion, up to a maximum of μₛN. Static friction only equals μₛN right at the verge of slipping, not in general. |
| Incline problem: sinθ or cosθ? | Set up axes along and perpendicular to the incline surface. The component of gravity PARALLEL to the surface (driving acceleration down the slope) is mg sinθ. The component PERPENDICULAR to the surface (balanced by the normal force) is mg cosθ. Mixing these up is the most common incline error. |
| Connected objects (string/pulley, blocks in contact) — what's shared, what's separate? | The magnitude of acceleration is the SAME for both objects (they're connected — a constraint). But each object gets its OWN free-body diagram and its OWN ΣF = ma equation; you then solve the two (or more) equations together. |
| Tension in a massless string — constant or changing? | For an ideal massless string over a massless, frictionless pulley, tension is the SAME throughout the string, including on both sides of the pulley. It only differs across a pulley if the pulley has mass/friction (beyond this course's scope). |
| "Equal and opposite forces cancel" — always true? | Only if both forces act on the SAME object (then they're balanced forces and the object is in equilibrium along that direction). Third Law pairs act on DIFFERENT objects and never cancel each other, since canceling requires being added on one free-body diagram. |

## Summary (write in your own words after studying)

Newton's three laws connect force to motion. The First Law says objects
resist changes in velocity (inertia) — no net force is needed to keep
something moving, only to change its motion. The Second Law, ΣF = ma, is
a vector relationship: resolve every force into components on a free-body
diagram, sum them per axis, and acceleration follows the net force,
scaling inversely with mass. The Third Law pairs every force with an
equal-and-opposite partner of the same type acting on a *different*
object, so those pairs never cancel. Weight (mg) is a force, distinct
from mass; normal force and friction are contact forces that adapt to
context (inclines, elevators, static vs. kinetic) rather than being fixed
multiples of weight. Connected-object systems share one acceleration
magnitude but require separate free-body diagrams per object.
