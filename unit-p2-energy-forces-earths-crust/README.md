# Unit P.2 — Energy, Forces, & Earth's Crust (OpenSciEd HS Physics)

**Real coursework and study materials** for OpenSciEd High School Physics, Unit 2, as taught at Corona del Mar High School. This folder is different from the rest of this repo: everything elsewhere is a generic, standards-based curriculum outline; **this is one real student's actual class**, built from the real slides, handouts, and teacher notes, plus study aids built to match.

**Unit question:** How do forces in Earth's interior determine what will happen to the surface we see?

> **📖 [Open the Unit P.2 Study Hub](https://claude.ai/artifact/V74qJrDYFySGyzXphpgyMo)** — every lesson below also has a formatted, interactive study-guide page (self-checks, worked examples, flip-card vocab, and an interactive practice test). The hub links to all of them. The markdown files in this folder are the source of truth; the linked pages are a more readable/study-friendly rendering of the same content.

## Why this unit uses a different structure than the rest of the repo

OpenSciEd organizes physics around **storylines** and a recurring **Matter–Energy–Force (M-E-F) triangle**, not a topic-by-topic outline. Every lesson answers one question, and each answer sets up the next one — so the folders here are numbered by the class's actual lesson sequence (Lesson 4 through Lesson 10), not by topic name. See [`../NGSS-ALIGNMENT.md`](../NGSS-ALIGNMENT.md) for how this unit's content maps onto the same NGSS performance expectations used elsewhere in this repo (primarily **HS-ESS2-1**, **HS-ESS1-5**, and **HS-PS1-8**, with **HS-PS4-1** for the seismic-wave content).

## A note on the Lessons 8–10 and test-prep content

Lessons 8–10 hadn't happened yet — and no teacher scans existed — when this study set was assembled, so that content (and the Unit 2 test prep) was built from the general OpenSciEd Unit P.2 storyline and standard, accurate Earth-science content (radiometric dating, rock density/isostasy, plate boundary types), written in the same Cornell-notes / M-E-F format the class already uses. **Once the actual class notes and teacher scans for Lessons 8–10 exist, swap them in** — the underlying physics and Earth science won't change, but the exact wording, examples, and emphasis the teacher used might differ from what's here. Treat this content as a strong first pass, not a replacement for the real class notes.

## How to use this folder

1. After each lesson, open that lesson's `cornell-notes.md` and fill in the blanks (Video/Turn-and-Talk prompts, summary) from what actually happened in class.
2. Do the practice sets with the answer key covered — check your reasoning against the key, not just your final answer.
3. Before the Lessons 4–7 quiz and the Unit 2 test, work through [`quiz-vocab-lessons-4-7.md`](quiz-vocab-lessons-4-7.md) / [`quiz-warmups-lessons-4-7.md`](quiz-warmups-lessons-4-7.md) and [`unit-2-test-prep/`](unit-2-test-prep/) respectively.
4. All files are plain Markdown (print-friendly, pastes cleanly into Google Docs) except the original teacher `.pptx`/`.docx` files, kept as-is for reference.
