# Assessment Criteria & Rubrics

## 1. Mastery scale (used for every learning objective)

| Level | Score | Descriptor | Evidence |
|---|---|---|---|
| 4 – Extending | 90–100% | Applies the concept to unfamiliar or multi-step situations; explains *why*, not just *how*. | Solves novel problems; spots errors in sample solutions; connects to real systems |
| 3 – Proficient | 80–89% | Solves standard problems accurately with correct units and diagrams. | Quiz ≥ 80%; practice set ≥ 80% correct |
| 2 – Developing | 65–79% | Correct on routine items; errors on multi-step or conceptual items. | Needs hints; misses sign/vector/unit details |
| 1 – Beginning | < 65% | Partial understanding; relies on formula-matching. | Needs reteaching |

**Proficiency target:** Level 3 on every objective before moving on; reassess Level 1–2 objectives using the quiz's
"Retry missed questions" mode and a new problem set.

## 2. Unit assessment weighting (suggested)

| Component | Weight |
|---|---|
| Cornell notes (complete, cues written, summary) | 10% |
| Practice problems (Given–Find–Equation–Answer format) | 15% |
| Lab report / design challenge | 20% |
| Interactive quiz (best attempt) | 10% |
| Unit test (concepts + problems + graph interpretation) | 45% |

## 3. Problem-solving rubric (4 points per problem)

| Criterion | 1 pt each |
|---|---|
| Diagram / free-body diagram / graph sketch with labeled quantities | ☐ |
| Correct equation chosen and stated | ☐ |
| Substitution with units and correct algebra | ☐ |
| Final answer with correct units, sign/direction, and a reasonableness statement | ☐ |

## 4. Lab report rubric (20 points)

| Criterion | Points |
|---|---|
| Question & hypothesis (testable, with predicted relationship) | 3 |
| Procedure & variables (independent, dependent, controlled; reproducible) | 3 |
| Data table & graph (labeled axes with units, best-fit line/curve) | 4 |
| Analysis (slope/area meaning, calculations, percent error/uncertainty) | 4 |
| Conclusion in **Claim–Evidence–Reasoning** form tied to a physics law | 4 |
| Sources of error & improvements (specific, not "human error") | 2 |

## 5. CER (Claim–Evidence–Reasoning) rubric

| | 0 | 1 | 2 |
|---|---|---|---|
| Claim | Missing/off-topic | Vague | Specific, answers the question |
| Evidence | None | Anecdotal | Quantitative data from lab/graph |
| Reasoning | None | Names law only | Links evidence to law with equation/mechanism |

## 6. Design challenge rubric (HS-PS2-3, HS-PS3-3) — 20 points

| Criterion | Points |
|---|---|
| Criteria & constraints stated (measurable) | 4 |
| Physics model used to predict performance (calculation) | 6 |
| Build/test with at least 2 iterations and data | 6 |
| Evaluation against criteria + redesign recommendation | 4 |

## 7. Using quiz results to track progress

- The quizzes record your best score per topic and the questions you missed (browser only).
- Each question is tagged with an objective code (e.g. `K3`); a missed tag means that objective needs review.
- Instructors can ask students to screenshot the "Results by objective" panel or copy the summary text for submission.
