# Assessment Criteria and Progress Tracker

## 1. Proficiency scale (apply to every learning objective)

| Level | Label | What it looks like |
|---|---|---|
| 4 | Extending | Solves unfamiliar, multi-step problems; explains why the method works; connects to another unit or a real system. |
| 3 | Proficient | Solves standard problems correctly with units and a diagram; explains reasoning in words; interprets graphs accurately. |
| 2 | Developing | Right idea but errors in setup, signs, or units; needs a hint or formula sheet; explanations partly correct. |
| 1 | Beginning | Mixes up core terms (e.g., speed/velocity, mass/weight); cannot start problems independently. |

Suggested grading weights: assessments 40%, labs 25%, practice and notes 20%, quizzes (best attempt) 15%.

## 2. Problem-solving rubric (use on tests and practice)

| Criterion | 3 pts | 2 pts | 1 pt | 0 |
|---|---|---|---|---|
| Diagram / representation | Labeled sketch, FBD, graph, or energy bar chart that matches the problem | Present, missing labels | Present but incorrect | None |
| Physics principle chosen | Names the correct law/equation and why | Correct equation, no reason | Partly relevant | Wrong |
| Math and algebra | Symbolic solution first, correct substitution | Minor algebra slip | Several errors | None |
| Units and significant figures | Correct throughout | One slip | Frequent slips | None |
| Sense check | States whether the answer is reasonable and why | Brief check | Check is wrong | None |

## 3. Lab report rubric (20 pts)

| Criterion | Pts |
|---|---|
| Question, hypothesis/prediction with physics reasoning | 3 |
| Procedure and variables (independent, dependent, controlled) | 3 |
| Data table with units and uncertainty | 3 |
| Graph (labeled axes, best-fit line, slope interpreted) | 4 |
| Analysis: claim, evidence, reasoning; percent error | 4 |
| Sources of error and improvements | 3 |

## 4. Quiz mastery rule

The interactive quizzes (`quizzes/index.html`) store each student's best score in their own browser. Mastery = **80% or higher** on two different days. Missed questions are re-offered with the "Retry missed" button. For grading, have students screenshot their results screen.
