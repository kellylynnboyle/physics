# Progress Checklist

A shared tracker for students and instructors. Copy this file (or a row
per student) into a spreadsheet/LMS gradebook if you want to track a
whole class; as-is it works for one student tracking their own progress.

**Proficiency bar (all units):** 80%+ on the unit quiz, practice problems
completed and self-checked, and the unit's `Assessment Criteria` rubric
met at the "Proficient" level or higher. See each unit's README for the
full rubric.
