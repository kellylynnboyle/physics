## Topic: Motion in Two Dimensions

| Cues / Questions | Notes |
|---|---|
| What is the core idea of projectile motion? | Horizontal (x) and vertical (y) motion happen **at the same time** but are completely **independent** of each other. |
| What is true about horizontal velocity during flight? | It never changes (ignoring air resistance): `vₓ = v₀ₓ` = constant the whole flight. |
| What is true about vertical motion during flight? | It's free fall: `a_y = −9.8 m/s²`, constant, for the entire flight — even at the very top. |
| How do I break an angled launch velocity into components? | `v₀ₓ = v₀ cos θ` (horizontal), `v₀ᵧ = v₀ sin θ` (vertical), θ measured from horizontal. |
| What variable connects the x and y motions? | **Time.** Time is the same for both — it's the only shared variable between the two independent motions. |
| How do I find time to reach maximum height? | Set `v_y = 0` and use `v_y = v₀ᵧ + a t` to solve for t. |
| How do I find total time of flight (level ground)? | Time up = time down, so total time = 2 × (time to reach max height). |
| How do I find maximum height? | Use vertical kinematics only: `Δy = v₀ᵧt + ½a t²` with t = time to reach max height. |
| How do I find range (horizontal distance)? | `Range = vₓ × t_total` — a horizontal equation using total flight time. |
| What angle maximizes range on level ground? | 45°. Complementary angles (e.g., 30° & 60°) give the *same* range but different heights/times. |
| Biggest mistake to avoid? | Plugging the full initial speed v₀ into a vertical OR horizontal equation instead of the correct component. Always split into vₓ and vᵧ FIRST. |
