| Cues / Questions | Notes |
|---|---|
| What's the difference between distance and displacement? | Distance = total path length traveled (scalar, always positive). Displacement = straight-line vector from start to end position (can be negative/zero even if distance traveled is large). Example: walking 10 m east then 10 m west → distance = 20 m, displacement = 0 m. |
| Speed vs. velocity? | Speed = distance/time (scalar). Velocity = displacement/time (vector). Average speed can differ from the magnitude of average velocity if the path isn't a straight line. |
| What is acceleration, really? | Rate of change of **velocity** (not just speed). a = Δv/Δt. An object can accelerate while slowing down (a and v opposite signs) or while moving at constant speed but changing direction (not covered by 1D equations). |
| What do the kinematic equations require? | Constant acceleration only. Identify which of the 5 variables (v₀, v, a, Δx, t) you're given and which you need — pick the equation missing the variable you don't have. |
| List the 4 kinematic equations | v = v₀ + at __ Δx = v₀t + ½at² __ v² = v₀² + 2aΔx __ Δx = ½(v₀ + v)t |
| How is free fall a special case? | a = −g = −9.8 m/s² (if up is positive), constant, same for all masses (ignoring air resistance). At the top of a vertical throw, v = 0 but a is still −9.8 m/s² — acceleration never zero in free fall. |
| Position-time graph: what does slope mean? | Slope = velocity. Steeper slope = faster. Flat line = at rest. Negative slope = moving in negative direction. Curved line = accelerating. |
| Velocity-time graph: what do slope and area mean? | Slope = acceleration. Area between the line and the time axis = displacement. A line below the axis = negative velocity (moving backward), still contributes area (displacement), but subtract if signed. |
| Common sign-convention trap | Once you pick "up/right = positive," every vector in the problem (v₀, v, a, Δx) must use that same convention for the whole problem — including gravity, which is negative if up is positive. |
| Common word-problem trap | "Starts from rest" means v₀ = 0. "Comes to a stop" means v = 0 (final velocity). "How high" at the top of the trajectory means v = 0 at that instant (not a = 0). |

## Summary (write in your own words after studying)

Kinematics describes motion using position, velocity, and acceleration as
vectors along a chosen axis. Under **constant acceleration**, four
equations connect five variables (v₀, v, a, Δx, t) — given any three, solve
for a fourth using the equation that omits the fifth. Free fall is
constant acceleration with a = −g. Graphs encode the same information:
slope of position-time = velocity; slope and area of velocity-time =
acceleration and displacement.
