# Unit 11: Earthquakes — Key Concepts

## Learning Objectives

By the end of this unit, students will be able to:
1. Describe the elastic rebound theory of how earthquakes occur.
2. Distinguish focus and epicenter, and P-waves, S-waves, and surface waves.
3. Explain how seismographs and triangulation locate an earthquake's epicenter.
4. Distinguish magnitude (Richter/moment magnitude) from intensity (Modified Mercalli).
5. Distinguish normal, reverse, and strike-slip faults and connect them to plate boundary types.
6. Explain why the logarithmic magnitude scale means each whole number increase represents a much larger earthquake.

## Vocabulary

| Term | Definition |
|---|---|
| Focus (hypocenter) | The underground point where an earthquake actually originates |
| Epicenter | The point on Earth's surface directly above the focus |
| P-wave (primary) | Fastest seismic wave; longitudinal; can travel through solids AND liquids |
| S-wave (secondary) | Slower than P-waves; transverse; can only travel through solids |
| Surface wave | Slowest but most destructive waves, traveling along Earth's surface |
| Magnitude | A measure of the energy released at the source (Richter scale or moment magnitude), logarithmic |
| Intensity | A measure of the shaking/damage felt at a specific location (Modified Mercalli scale), varies by distance from epicenter |
| Elastic rebound theory | Stress builds up along a fault until rock suddenly breaks/snaps back, releasing energy as an earthquake |
| Normal fault | Hanging wall moves down relative to footwall (associated with tension/divergent boundaries) |
| Reverse fault | Hanging wall moves up relative to footwall (associated with compression/convergent boundaries) |
| Strike-slip fault | Blocks move horizontally past each other (associated with transform boundaries) |

## Core Ideas

- **Triangulation:** using the time delay between P-wave and S-wave arrival
  at three or more seismograph stations to calculate distance to the
  epicenter from each station, then finding where those distance circles
  intersect.
- **Magnitude scale is logarithmic:** each whole-number increase represents
  roughly 10× the ground motion amplitude and about 32× the energy released.

## The Big Idea

**One earthquake has exactly one magnitude, but many different
intensities.** Magnitude describes the energy released at the source — a
single, fixed number for that quake. Intensity describes how much shaking
is *felt* at a specific location, which varies with distance from the
epicenter, local geology, and building construction — the same earthquake
can be "severe" in one town and barely noticeable a few hundred miles away.

## Common Misconceptions to Address Directly

- Treating magnitude and intensity as the same thing (magnitude = one fixed
  number per earthquake, describing energy at the source; intensity =
  varies by location, describing felt effects).
- Believing the Richter/magnitude scale is linear (it's logarithmic — a
  magnitude 6 quake isn't twice as strong as a magnitude 3, it's roughly
  1,000× more energetic).
- Believing S-waves can travel through Earth's liquid outer core (they
  can't — S-waves only travel through solids, which is actually how
  scientists first discovered the outer core is liquid: S-waves create a
  "shadow zone" where they don't arrive).
- Confusing focus and epicenter (focus = underground origin point;
  epicenter = the point directly above it on the surface).
- Believing all faults behave the same way — fault type (normal, reverse,
  strike-slip) depends on the type of stress and plate boundary involved.
