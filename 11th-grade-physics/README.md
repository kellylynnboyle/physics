# 11th Grade Physics — Mechanics Learning Project

A self-contained study project covering the core mechanics unit for 11th grade
physics: **Kinematics, Projectile Motion, Newton's Laws, Momentum, and Work &
Energy**. Each section includes a concept guide, Cornell notes, and an
interactive quiz built from the questions students most often get wrong.

## How to Use This Project

**Students:** Work through each section in order — they build on one
another (kinematics → projectile motion → Newton's Laws → momentum → work
& energy). For each topic:
1. Read the section `README.md` for key concepts, equations, and worked
   real-world applications.
2. Fill out / review the `cornell-notes.md` (use it during class, then
   revisit before the quiz).
3. Work the practice problems and check them against the answer key.
4. Open `quiz.html` in any web browser and take the interactive quiz. It
   targets the mistakes students make most often, with explanations for
   every answer choice.
5. Check off the objectives below once you can do them without help.

**Instructors:** The learning objectives and assessment criteria in each
section README map to gradable outcomes. The quizzes can be used as
formative checks (ungraded, retake until mastery) or exit tickets. Practice
problems include answer keys for quick grading.

## Unit Checklist

### 📐 Section 1 — Kinematics
- [ ] Distinguish distance/displacement and speed/velocity
- [ ] Interpret position–time and velocity–time graphs (slope & area)
- [ ] Apply the four kinematic equations to 1D motion
- [ ] Solve free-fall problems, including "thrown upward" cases
- [ ] Complete Cornell notes for Kinematics
- [ ] Score 80%+ on the Kinematics quiz

### 🎯 Section 2 — Projectile Motion
- [ ] Decompose initial velocity into horizontal/vertical components
- [ ] Explain why horizontal and vertical motion are independent
- [ ] Calculate time of flight, max height, and range
- [ ] Solve horizontally-launched and angled-launch problems
- [ ] Complete Cornell notes for Projectile Motion
- [ ] Score 80%+ on the Projectile Motion quiz

### ⚖️ Section 3 — Newton's Laws
- [ ] State and apply Newton's 1st, 2nd, and 3rd Laws
- [ ] Draw correct free-body diagrams
- [ ] Distinguish mass vs. weight and static vs. kinetic friction
- [ ] Identify action–reaction pairs correctly
- [ ] Complete Cornell notes for Newton's Laws
- [ ] Score 80%+ on the Newton's Laws quiz

### 💥 Section 4 — Momentum
- [ ] Calculate momentum and impulse (p = mv, J = FΔt = Δp)
- [ ] Apply conservation of momentum to 1D collisions
- [ ] Distinguish elastic, inelastic, and perfectly inelastic collisions
- [ ] Solve 2-object collision problems for unknown velocities
- [ ] Complete Cornell notes for Momentum
- [ ] Score 80%+ on the Momentum quiz

### 🔋 Section 5 — Work & Energy
- [ ] Calculate work, including cases where W = 0
- [ ] Apply the work–energy theorem
- [ ] Calculate kinetic, gravitational PE, and elastic PE
- [ ] Apply conservation of mechanical energy, including energy "lost" to friction
- [ ] Calculate power
- [ ] Complete Cornell notes for Work & Energy
- [ ] Score 80%+ on the Work & Energy quiz

## Unit-Level Learning Objectives

By the end of this unit, students should be able to:
1. Model 1D and 2D motion using vectors, graphs, and kinematic equations.
2. Apply Newton's Laws to analyze forces on objects in equilibrium and
   accelerating systems, including friction.
3. Apply conservation of momentum to predict outcomes of collisions.
4. Apply conservation of energy and the work–energy theorem to systems with
   and without friction.
5. Connect each concept to a real-world engineering or safety application
   (e.g., car crashes, sports, roller coasters, ballistics).

## Assessment Criteria (Suggested Rubric)

| Level | Description |
|---|---|
| **Mastery (90–100%)** | Solves multi-step problems independently, explains reasoning with correct units and vector direction, connects concept to real-world application. |
| **Proficient (80–89%)** | Solves standard problems correctly with minor errors (units, sig figs); needs occasional prompting on multi-step problems. |
| **Developing (65–79%)** | Understands concept qualitatively but makes recurring errors applying equations or reading graphs. |
| **Beginning (<65%)** | Requires re-teaching of core concept before practicing further. |

Suggested weighting per section: Cornell notes completion (10%), practice
problem set (30%), quiz score — best of up to 3 attempts (30%), unit test
question cluster (30%).
