# Unit 2: Projectile Motion — Key Concepts

## Learning Objectives

By the end of this unit, students will be able to:
1. Explain why horizontal and vertical motion in projectile problems are independent of each other.
2. Identify that horizontal velocity is constant (no horizontal acceleration, ignoring air resistance) while vertical motion is free fall (a = -g).
3. Solve for time of flight, range, and maximum height for both horizontally-launched and angled-launch projectiles.
4. Decompose an initial velocity into horizontal and vertical components using trigonometry.
5. Explain why maximum range (on level ground) occurs at a 45° launch angle.
6. Correctly identify symmetric properties of projectile trajectories (e.g., time up = time down on level ground).

## Vocabulary

| Term | Definition |
|---|---|
| Projectile | Any object launched into the air, moving under gravity alone after launch (no thrust, ignoring air resistance) |
| Trajectory | The curved (parabolic) path of a projectile |
| Range | Horizontal distance traveled before landing at the same height it was launched |
| Time of flight | Total time the projectile is in the air |
| Vₓ | Horizontal component of velocity — constant throughout flight |
| Vy | Vertical component of velocity — changes due to gravity (a = -g) |
| Launch angle (θ) | Angle above the horizontal at which the projectile is launched |

## Core Formulas

Component decomposition: Vₓ = V₀cos(θ), Vy = V₀sin(θ)

**Horizontal motion (constant velocity):** x = Vₓ · t

**Vertical motion (free fall — same 4 kinematic equations from Unit 1, applied only to the y-direction):**
- Vy = Vy₀ - gt
- y = Vy₀t - ½gt²
- Vy² = Vy₀² - 2gΔy

**Special case — launched horizontally from a height h (Vy₀ = 0):**
- Time to fall: t = √(2h/g)
- Range: x = V₀ · t

**Special case — launched at angle θ, landing at same height:**
- Time of flight: t = (2·V₀sin θ)/g
- Max height: H = (V₀sin θ)²/(2g)
- Range: R = (V₀²sin(2θ))/g

## The Big Idea (say this out loud, it's the whole unit)

**Horizontal and vertical motion happen at the same time but don't affect
each other.** Gravity only acts vertically — it never speeds up or slows
down the horizontal motion. This is why a bullet fired perfectly
horizontally and a bullet simply dropped from the same height hit the
ground at the *exact same time*, even though one is also moving forward.

## Common Misconceptions to Address Directly

- Thinking horizontal velocity decreases over the flight (it doesn't — only vertical velocity changes, from gravity).
- Using the same "t" incorrectly across x and y equations by mixing up Vₓ and Vy in a formula meant for the other axis.
- Believing a heavier or faster-moving projectile "falls slower" — vertical motion (fall time) does not depend on horizontal speed or mass.
- Believing max range always uses V₀ directly instead of decomposing into components first.
