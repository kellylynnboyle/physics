# Unit 1: Kinematics — Assessment & Mastery Checklist

## Student Self-Assessment

Rate yourself honestly on each objective (1 = Emerging, 2 = Developing,
3 = Proficient, 4 = Advanced). "Proficient" means you could solve a new
problem of this type on a test without help.

| Objective | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| Distinguish distance/displacement and speed/velocity | | | | |
| Read/construct x-t, v-t, a-t graphs and translate between them | | | | |
| Use slope and area on v-t graphs correctly | | | | |
| Select and apply the correct kinematic equation | | | | |
| Solve multi-stage motion problems | | | | |
| Solve free-fall problems with correct sign convention | | | | |

## Instructor Mastery Rubric

| Level | Evidence |
|---|---|
| **Emerging (1)** | Confuses distance/displacement or speed/velocity; cannot select a kinematic equation without a prompt; sign errors on nearly every free-fall problem. |
| **Developing (2)** | Solves single-stage problems correctly with a formula sheet; still needs support choosing which equation fits which given/unknown; graph translation (x-t ↔ v-t) is inconsistent. |
| **Proficient (3)** | Independently solves single- and two-stage kinematics problems; correctly reads slope/area off graphs; handles free-fall sign convention without prompting; scores ≥80% on unit quiz. |
| **Advanced (4)** | Solves multi-stage and non-standard problems (e.g., objects passing each other, relative motion); can justify equation choice and explain misconceptions (e.g., why v=0 ≠ a=0) to a peer; scores ≥90% on unit quiz. |

## Gradable Evidence Checklist (for instructors)

- [ ] Unit quiz score recorded (target ≥80%)
- [ ] At least 3 practice problems shown with full work (not just final answers)
- [ ] Cornell notes cue-column self-quiz completed
- [ ] One real-world application explained in the student's own words (written or oral)
- [ ] Free-fall sign convention checked explicitly (common enough error to spot-check individually)

## Suggested Exit Ticket (3 questions, 5 minutes)

1. Sketch a v-t graph for: "A skateboarder speeds up steadily for 4 s, then coasts at constant speed for 3 s, then brakes to a stop over 2 s."
2. A ball is dropped from 20 m. How long until it hits the ground?
3. Explain in one sentence why "negative acceleration" doesn't always mean "slowing down."
