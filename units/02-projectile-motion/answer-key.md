# Unit 2: Projectile Motion — Answer Key (instructors)

## Quiz

| # | Answer | Why | Mistake this question targets | Objective |
|---|---|---|---|---|
| 1 | **C.** They hit at the same time | Both start with zero vertical velocity and fall the same height with the same acceleration. Horizontal speed does not change the fall time. | Thinking horizontal speed keeps an object in the air longer. | |
| 2 | **C.** Horizontal, equal to vx | Only the vertical component is zero at the top. The horizontal component never changes, so the ball is still moving sideways at vx. | Carrying over "velocity is zero at the top" from a straight-up toss. | |
| 3 | **B.** 9.8 m/s² downward | Gravity is the only force at every point of the flight, so the acceleration is 9.8 m/s² downward the whole time. | Thinking acceleration vanishes where the vertical velocity is zero. | |
| 4 | **C.** It stays constant | No horizontal force acts, so there is no horizontal acceleration and vx stays the same from launch to landing. | Believing a moving object naturally slows down without a force. | |
| 5 | **B.** Directly above the package | The package keeps the plane's horizontal velocity after release, so it stays directly below the plane as it falls. | Thinking the package loses its forward motion when released. | |
| 6 | **A.** Gravity only | The hand's force ends when contact ends. The ball keeps moving forward because of inertia, with gravity as the only force. | Believing a forward force travels with the ball. | |
| 7 | **B.** The same time | Fall time depends only on the table height: t = √(2y / g). The faster marble lands twice as far away in the same time. | Linking time in the air to horizontal speed. | |
| 8 | **C.** They land at the same distance | Complementary angles give the same range. The 60° ball is in the air longer but has a smaller horizontal velocity, and the two effects cancel. | Assuming a higher or a flatter launch always goes farther. | |
| 9 | **C.** 5.0 m | Vertical: t = √(2 × 4.9 / 9.8) = 1.0 s. Horizontal: x = 5.0 × 1.0 = 5.0 m. | Mixing the height into the horizontal equation. | |
| 10 | **A.** 10 m/s | vy = v·sin θ = 20 × sin 30° = 10 m/s. The 17.3 m/s value is the horizontal component, 20 × cos 30°. | Swapping sine and cosine. | |

## Practice problems

1. A soccer ball is kicked at 25 m/s at 37° above the ground. Find vx and vy.  
   **Answer:** vx = 25 cos 37° = 20 m/s; vy = 25 sin 37° = 15 m/s.
2. A stone is thrown horizontally at 8.0 m/s from a 19.6 m cliff. How long is it in the air and how far from the base does it land?  
   **Answer:** t = √(2 × 19.6 / 9.8) = 2.0 s; x = 8.0 × 2.0 = 16 m.
3. A ball rolls off a 0.80 m table and lands 1.2 m from its base. How fast was it rolling?  
   **Answer:** t = √(2 × 0.80 / 9.8) = 0.404 s; vx = 1.2 / 0.404 = 3.0 m/s.
4. A ball is launched at 30 m/s at 60°. Find the time in the air, the maximum height, and the range on level ground.  
   **Answer:** vy = 26.0 m/s, vx = 15.0 m/s; time = 2(26.0)/9.8 = 5.3 s; H = 26.0² / 19.6 = 34 m; R = 15.0 × 5.3 = 80 m.
5. The same ball is launched at 30 m/s at 30° instead. Compare its range with the 60° launch.  
   **Answer:** vy = 15.0 m/s, vx = 26.0 m/s; time = 3.06 s; R = 26.0 × 3.06 = 80 m. Same range, lower and quicker flight.
6. A plane flying level at 50 m/s drops a supply crate from 490 m. How far ahead of the target must it release?  
   **Answer:** t = √(2 × 490 / 9.8) = 10 s; x = 50 × 10 = 500 m.
