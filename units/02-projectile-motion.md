# Unit 2: Projectile Motion

**NGSS link:** HS-PS2-1 (mathematical representations of motion under a constant net force).
**Suggested pacing:** 1.5-2 weeks. **Prerequisites:** Unit 1, right-triangle trig.

## Learning objectives (I can...)
- [ ] P1. Resolve a velocity vector into horizontal and vertical components.
- [ ] P2. Explain that x and y motion are independent and share only time.
- [ ] P3. Solve horizontal-launch problems (time from height, range from time).
- [ ] P4. Solve angled-launch problems: time of flight, max height, range.
- [ ] P5. Predict how launch angle and speed affect range; state the 45° and complementary-angle results.
- [ ] P6. Design and test a launch that hits a target; evaluate sources of error (air resistance, measurement).

## Key concepts
| Concept | Essentials |
|---|---|
| Components | v_x = v cos θ; v_y = v sin θ |
| Horizontal | a_x = 0; x = v_x t |
| Vertical | a_y = −9.8 m/s²; use the Unit 1 equations |
| Symmetry | On level ground, time up = time down; speed at equal heights is equal |
| Range | R = v² sin 2θ / g (level ground) |

## Cornell notes (fill-in format)
| Cue / Questions | Notes |
|---|---|
| What is independence of motion? | Horizontal and vertical motions don't affect each other; time connects them. |
| What is the acceleration in the x-direction? | Zero (no horizontal force, ignoring air). Horizontal speed is constant. |
| What is true at the top of the path? | v_y = 0, v_x ≠ 0, a = 9.8 m/s² down. |
| How do I start any problem? | Split into x and y tables. Find time from y, apply it to x. |
| Which angles give the same range? | Complementary angles (30° & 60°). Max range at 45°. |
| Why does a horizontally-launched object fall at the same rate as a dropped one? | Both have v_y = 0 at the start and the same g. |
| **Summary** | _Students: explain independence in your own words and sketch a trajectory with velocity components at 3 points._ |

## Most-missed questions
Quiz: `quiz/index.html` → **Projectile Motion**. Top traps: using the full speed in a vertical equation; thinking a = 0 at the top; believing faster horizontal throws fall more slowly.

## Practice problems
1. A ball rolls off a 1.25 m table at 2.0 m/s. Find the landing distance. *(≈ 1.0 m)*
2. A soccer ball is kicked at 20 m/s at 37° (sin ≈ 0.6, cos ≈ 0.8). Find the flight time and range. *(≈ 2.4 s, ≈ 39 m)*
3. Show that 30° and 60° give the same range at 15 m/s.
4. A plane flying at 100 m/s drops a package from 500 m. How far ahead of the target must it release? *(≈ 1010 m)*
5. Challenge: Find the angle that maximizes the range when launching from a cliff. Is it still 45°?

## Real-world applications
Sports (basketball arc, long jump, javelin), emergency water streams from fire hoses, ballistic design, video game physics engines, and airdrop aid.

## Lab
**Launch & land:** use a spring launcher or ramp-launched marble. Predict the landing spot from measured launch speed, place a cup target, and report the percent error.
