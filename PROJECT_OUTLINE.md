# Physics 11 — Mechanics Project Outline & Checklist

**Course:** Physics (11th grade) — California NGSS Physics & Earth Science
course model
**Semester 1 focus:** Kinematics → Projectile Motion → Newton's Laws →
Momentum → Work & Energy
**Standards reference:** [CDE NGSS Standards](https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp)

This document is the shareable project outline. It ties the five topic
folders together, states the standards each one builds toward, and gives
instructors a single place to track class progress.

---

## How this project is organized

| Topic | Folder | NGSS anchor |
|---|---|---|
| 1. Kinematics | [`topics/01-kinematics`](topics/01-kinematics/notes.md) | Foundational skill for HS-PS2-1 (no dedicated PE; prerequisite math/graphing for motion) |
| 2. Projectile Motion | [`topics/02-projectile-motion`](topics/02-projectile-motion/notes.md) | Applies kinematics in 2D; supports HS-PS2-1 |
| 3. Newton's Laws | [`topics/03-newtons-laws`](topics/03-newtons-laws/notes.md) | **HS-PS2-1** |
| 4. Momentum | [`topics/04-momentum`](topics/04-momentum/notes.md) | **HS-PS2-2, HS-PS2-3** |
| 5. Work & Energy | [`topics/05-work-and-energy`](topics/05-work-and-energy/notes.md) | **HS-PS3-1, HS-PS3-2, HS-PS3-3** |

> Note: NGSS is phenomena- and performance-based, not organized around
> traditional unit names. Kinematics and projectile motion don't have their
> own Performance Expectations — they're the math and modeling skills
> students need before HS-PS2-1 (forces and acceleration) makes sense.
> Newton's Laws, Momentum, and Work & Energy map directly onto PS2/PS3
> Performance Expectations as noted above.

Each topic folder contains:

- **Key Concepts** — the vocabulary and relationships students must master
- **Cornell Notes** — a cue/note/summary template pre-seeded with content
- **Common Misconceptions** — what trips students up, and why
- **Learning Objectives & Assessment Criteria** — what "mastery" looks like
- **Resources & Practice Problems**
- **Real-World Applications**
- **`quiz.html`** — an interactive, self-grading quiz built from the
  questions students most often get wrong on that topic, each with an
  explanation

## Master Checklist

Instructors and students can copy this table per-student or per-class to
track progress. Check off each row as it's completed.

### Unit 1 — Kinematics
- [ ] Read Key Concepts & complete Cornell notes
- [ ] Practice problems (position, velocity, acceleration; d-t, v-t, a-t graphs)
- [ ] Lab: motion detector / constant velocity & acceleration
- [ ] Interactive quiz — score ≥ 80%
- [ ] Unit assessment

### Unit 2 — Projectile Motion
- [ ] Read Key Concepts & complete Cornell notes
- [ ] Practice problems (horizontal launch, angled launch, range/time of flight)
- [ ] Lab: projectile launcher / trajectory mapping
- [ ] Interactive quiz — score ≥ 80%
- [ ] Unit assessment

### Unit 3 — Newton's Laws
- [ ] Read Key Concepts & complete Cornell notes
- [ ] Practice problems (F = ma, free-body diagrams, friction, Newton's 3rd law pairs)
- [ ] Lab: force/acceleration relationship (Atwood machine, cart & track, or PhET)
- [ ] Interactive quiz — score ≥ 80%
- [ ] Unit assessment — evidence for HS-PS2-1

### Unit 4 — Momentum
- [ ] Read Key Concepts & complete Cornell notes
- [ ] Practice problems (p = mv, impulse-momentum theorem, elastic/inelastic collisions)
- [ ] Lab/design task: crumple zone or egg-drop device (HS-PS2-3)
- [ ] Interactive quiz — score ≥ 80%
- [ ] Unit assessment — evidence for HS-PS2-2 and HS-PS2-3

### Unit 5 — Work & Energy
- [ ] Read Key Concepts & complete Cornell notes
- [ ] Practice problems (work, KE, PE, conservation of mechanical energy, power)
- [ ] Lab: roller coaster / pendulum energy conservation
- [ ] Interactive quiz — score ≥ 80%
- [ ] Unit assessment — evidence for HS-PS3-1, HS-PS3-2, HS-PS3-3

### Semester wrap-up
- [ ] Cumulative review across all five units
- [ ] Semester 1 final assessment
- [ ] Portfolio check: all five Cornell notes sets complete and legible

## How progress is tracked (assessment model)

Each unit uses the same three-part evidence model:

1. **Formative** — the interactive quiz in each topic folder (`quiz.html`).
   Not graded for a letter grade; used to catch misconceptions before the
   unit test. Students should retake it until they consistently score 80%+.
2. **Application** — the practice problems and lab/design task listed in
   each topic's `notes.md`, scored against that topic's Assessment
   Criteria.
3. **Summative** — the unit assessment, which mixes conceptual questions
   (matching the quiz style) with multi-step numerical problems and, where
   noted, a design or data-analysis task tied to the NGSS Performance
   Expectation.

## For instructors

- The quizzes are static HTML/JS files — no server, account, or internet
  connection required. They run entirely in the browser and can be
  distributed as files, hosted on a class site, or opened directly from
  this repository.
- Each topic's "Common Misconceptions" section is drawn from the most
  frequently missed question types on standard AP Physics 1 / conceptual
  physics diagnostics (e.g., FCI-style items) — use it to target warm-ups
  and reteaching.
- Learning Objectives are written as "Students will be able to..." (SWBAT)
  statements so they can be dropped directly into a syllabus or gradebook.
