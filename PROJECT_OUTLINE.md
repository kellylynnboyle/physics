# Master Project Outline & Checklist

Use this as the shared tracker between students and instructors. Check off each row as it's completed; the "Assessment Criteria" column defines what "mastered" means for grading.

## Unit-level learning objectives

By the end of this project, students will be able to:

- [ ] Analyze and predict motion in one and two dimensions using kinematic equations and graphs
- [ ] Apply Newton's three laws to solve for unknown forces, masses, and accelerations in single- and multi-object systems
- [ ] Apply conservation of momentum to solve elastic and inelastic collision problems
- [ ] Apply the work-energy theorem and conservation of mechanical energy to solve motion problems without directly using kinematics
- [ ] Choose the correct physics model (kinematics vs. forces vs. momentum vs. energy) for a given real-world scenario, and justify the choice

## Topic-by-topic checklist

### 1. Kinematics — 4 class days
- [ ] Read concept overview (`topics/01-kinematics/README.md`)
- [ ] Complete Cornell notes
- [ ] Score 80%+ on most-missed-questions quiz
- [ ] Complete practice problem set
- [ ] Submit one real-world application write-up (2–3 sentences)

**Learning objectives**
- Distinguish distance/displacement and speed/velocity
- Read position, velocity, and acceleration from position-time and velocity-time graphs (and vice versa)
- Apply the four kinematic equations to solve for an unknown in constant-acceleration motion
- Solve free-fall problems using g = 9.8 m/s²

**Assessment criteria (mastery)**
- Correctly identifies which kinematic equation to use given the known/unknown variables (no "guess and check")
- Correctly computes slope and area under the curve on motion graphs, including units
- Distinguishes vector quantities (velocity, acceleration, displacement) from scalar quantities (speed, distance) in written answers, including sign conventions

### 2. Projectile Motion — 3 class days
- [ ] Read concept overview (`topics/02-projectile-motion/README.md`)
- [ ] Complete Cornell notes
- [ ] Score 80%+ on most-missed-questions quiz
- [ ] Complete practice problem set
- [ ] Submit one real-world application write-up

**Learning objectives**
- Decompose an initial velocity into horizontal and vertical components
- Explain why horizontal and vertical motion are independent
- Solve for time of flight, range, and maximum height for horizontal and angled launches
- Explain why horizontal velocity is constant while vertical velocity changes

**Assessment criteria (mastery)**
- Correctly sets up vx = v·cosθ and vy = v·sinθ without prompting
- Treats horizontal and vertical motion as two separate 1D kinematics problems linked only by time
- Correctly identifies that maximum range occurs at 45° (level launch/landing) and explains why

---

### 3. Newton's Laws — 4 class days
- [ ] Read concept overview (`topics/03-newtons-laws/README.md`)
- [ ] Complete Cornell notes
- [ ] Score 80%+ on most-missed-questions quiz
- [ ] Complete practice problem set
- [ ] Submit one real-world application write-up

**Learning objectives**
- State and explain Newton's 1st, 2nd, and 3rd laws in your own words
- Draw a correct free-body diagram for an object in any scenario (incline, pulley, tension, friction)
- Apply ΣF = ma to solve for acceleration, force, or mass, including multi-body systems
- Correctly identify Newton's third-law force pairs and explain why they don't cancel

**Assessment criteria (mastery)**
- Free-body diagrams include all forces acting *on* the object only (no forces the object exerts on other things)
- Correctly separates forces into x- and y-components on incline problems
- Explains, without error, why a heavier object doesn't fall faster in the absence of air resistance
- Correctly distinguishes a third-law pair (same object pair, opposite objects) from a balanced-force pair (same object, net force = 0)

---

### 4. Momentum — 3–4 class days
- [ ] Read concept overview (`topics/04-momentum/README.md`)
- [ ] Complete Cornell notes
- [ ] Score 80%+ on most-missed-questions quiz
- [ ] Complete practice problem set
- [ ] Submit one real-world application write-up

**Learning objectives**
- Calculate momentum and impulse, and relate impulse to change in momentum (impulse-momentum theorem)
- Apply conservation of momentum to elastic and perfectly inelastic collisions in 1D
- Distinguish elastic from inelastic collisions using kinetic energy before/after
- Explain how airbags, crumple zones, and follow-through use impulse-time relationships

**Assessment criteria (mastery)**
- Correctly sets up conservation of momentum with consistent sign conventions for direction
- Distinguishes "momentum is always conserved in a closed system" from "kinetic energy is only conserved in elastic collisions"
- Uses FΔt = Δp correctly to reason about force reduction over longer contact time

---

### 5. Work, Energy & Power — 4–5 class days
- [ ] Read concept overview (`topics/05-work-energy/README.md`)
- [ ] Complete Cornell notes
- [ ] Score 80%+ on most-missed-questions quiz
- [ ] Complete practice problem set
- [ ] Submit one real-world application write-up

**Learning objectives**
- Calculate work done by a constant force, including cases where force and displacement aren't parallel
- Apply the work-energy theorem (W_net = ΔKE)
- Apply conservation of mechanical energy (KE + PE) to solve motion problems, identifying when energy is/isn't conserved
- Calculate power as the rate of energy transfer or work

**Assessment criteria (mastery)**
- Correctly identifies when a force does zero work (perpendicular to motion, or no displacement)
- Correctly applies conservation of energy only when non-conservative forces (friction, air resistance) are negligible or explicitly accounted for
- Distinguishes energy (a scalar, in joules) from power (a rate, in watts) in both calculations and explanations

## Cumulative unit assessment

After all five topics, students should be able to complete a mixed-topic problem set that requires them to *identify* which model (kinematics, forces, momentum, or energy) applies before solving — this is the highest-leverage skill for standardized tests (AP Physics 1, SAT Subject-style, state exams) and should be weighted accordingly in a final unit test.
