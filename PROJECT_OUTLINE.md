# 11th Grade Physics — Learning Project Outline

A shareable checklist and roadmap for a five-unit mechanics sequence: **Kinematics → Projectile Motion → Newton's Laws → Momentum → Work & Energy**. Each unit builds on the one before it (motion description → motion in 2D → causes of motion → conservation law #1 → conservation law #2), so the recommended sequence is the listed order.

Each unit folder under [`topics/`](./topics) contains the same three deliverables:

| File | Purpose |
|---|---|
| `README.md` | Key concepts, equations, learning objectives, assessment rubric, common misconceptions, resources, real-world applications, and practice problems |
| `cornell-notes.md` | Cornell-format notes (cue/question column + notes column + summary) ready to print or copy into a notebook |
| `quiz.html` | A self-contained, offline-friendly interactive quiz (open directly in any browser) targeting the questions students miss most often on that topic, with instant feedback and a scored result |

## How Progress Is Tracked

Each unit uses the same 4-level rubric (defined in full inside each unit's README under **Assessment Criteria**):

| Level | Meaning |
|---|---|
| **4 — Mastery** | Solves multi-step and applied problems independently; explains reasoning; no conceptual errors |
| **3 — Proficient** | Solves standard problems correctly with only minor, non-conceptual errors |
| **2 — Developing** | Needs support identifying the right approach; recurring conceptual gaps |
| **1 — Beginning** | Cannot apply the core relationship/law independently |

**Suggested evidence per unit:** the unit's practice problems, the `quiz.html` score (target: 80%+, retakeable), one instructor-led check-in (free-response or lab-based), and a cumulative assessment at the end of the sequence that draws on all five units together.

## Standards Alignment Note

This sequence maps to a standard introductory (algebra-based) mechanics unit — comparable to NGSS HS-PS2 (Motion and Stability: Forces and Interactions) and typical state Physics I / Physical Science standards covering 1D and 2D kinematics, Newton's laws, and the conservation of momentum and energy. Instructors should cross-check against their specific state or district standards.
