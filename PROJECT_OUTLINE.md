| 2 | [Projectile Motion](projectile-motion/) | 1.5 weeks |

## Cumulative assessment criteria (instructor use)

| Level | Description |
|---|---|
| **Exceeds (A)** | Solves multi-step, multi-concept problems (e.g., a projectile that then undergoes a collision) with correct units, sig figs, and a labeled diagram; can justify method choice (e.g., "energy is faster here than kinematics because height is unknown"). |
| **Meets (B/C)** | Solves standard single-concept problems correctly with proper setup (given/find/equation/solve/units) and can explain reasoning verbally or in writing. |
| **Approaching (D)** | Recognizes which topic/equation applies but makes algebra, sign, or unit errors; needs support to get to a final numeric answer. |
| **Beginning (F)** | Cannot identify which concept or equation applies without significant scaffolding. |

Recommended grade weighting per unit: Cornell notes/participation 10%,
practice problem sets 30%, interactive quiz 20%, unit test 40%.

## Cross-cutting skills reinforced in every unit

- Setting up a problem: given / find / diagram / equation / solve / check units
- Vector vs. scalar reasoning and sign conventions
- Reading and constructing graphs (position-time, velocity-time,
  force-time as applicable)
- Order-of-magnitude sanity checking of answers
- Communicating reasoning, not just a final number
