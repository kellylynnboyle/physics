# Instructor Guide

## Semester 1 pacing (≈ 16 weeks; adjust to your calendar)
| Weeks | Unit | Key lab / task |
|---|---|---|
| 1 | Course launch: measurement, units, significant figures, graphing, Cornell-notes routine | Pre-assessment, lab safety |
| 2–4 | 1 Kinematics | Motion-sensor lab |
| 5–6 | 2 Projectile Motion | Launcher prediction lab |
| 7–10 | 3 Newton's Laws | a vs. F / a vs. 1/m lab |
| 11–13 | 4 Momentum | Collision-cart lab + safety-device design |
| 14–16 | 5 Work & Energy | Energy conservation lab + conversion device |
| Finals | Cumulative review | Semester exam |

## Weekly routine
1. **Monday:** Launch with a phenomenon or demo and a prediction (CER warm-up). Students start Cornell notes (cue column left blank).
2. **Tuesday–Wednesday:** Mini-lessons, simulation or lab, worked examples.
3. **Thursday:** Practice problems, IXL skills, whiteboard sessions.
4. **Friday:** Interactive quiz (10 min), exit ticket, error analysis on missed items.

## Using the interactive quizzes
- Open `quizzes/index.html` in any modern browser (works offline). To share with students, host the repository with GitHub Pages or copy the `quizzes/` folder to your LMS.
- Each unit has 9 questions built around the common misconceptions listed under each answer. Use the "Common misconception" tags to plan reteaching.
- Edit or add questions in `quizzes/<unit>.js`. Format of each entry: `{ q, choices[], answer (index), why, misconception }`.

## Differentiation
- **Support:** Provide equation sheets with units; sentence frames for CER; use PhET to build intuition first; allow graph-first approaches.
- **Extension:** Challenge problems at the end of each practice set; derive range formula; analyze real video with Tracker; two-dimensional collisions.
- **English learners:** Pre-teach vocabulary (displacement, net force, impulse) with diagrams; bilingual glossaries; sentence starters in Cornell cue column.

## Common misconceptions to watch (cross-unit)
| Misconception | Unit | Counter-activity |
|---|---|---|
| Velocity zero ⇒ acceleration zero | 1 | Vertical toss with motion sensor |
| Heavier objects fall faster | 1 | Vacuum-tube video; coin and paper |
| Horizontal speed affects fall time | 2 | Simultaneous drop and launch |
| Force is needed to keep things moving | 3 | Puck/air-track demo |
| Bigger object exerts bigger force in a collision | 3 | Two force sensors pushing each other |
| Momentum and energy are interchangeable | 4 | Compare p and KE data tables |
| Carrying a load = work | 5 | Define work; check θ |

## Materials checklist
Motion sensors or smartphones with video; dynamics carts and tracks; spring or marble launchers; photogates (optional); force sensors or spring scales; meter sticks, stopwatches, carbon paper; egg-drop or crash-test supplies; computers/Chromebooks for simulations and quizzes.

## Safety
Eye protection for launchers and springs; secure carts on tracks; designate drop zones for design challenges.
