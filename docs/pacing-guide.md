# Suggested Pacing (Semester 1, ~18 weeks)

| Weeks | Unit | Key activities |
|-------|------|----------------|
| 1 | Course launch | Safety, measurement, graphing review, diagnostic quiz |
| 2–4 | 1 Kinematics | Motion-sensor / video-analysis lab, graph matching |
| 5–6 | 2 Projectile Motion | Launcher lab, "monkey and hunter" demo |
| 7–10 | 3 Newton's Laws | Cart-and-fan-cart lab (F=ma), friction lab, free-body diagrams |
| 11–13 | 4 Momentum | Collision carts, egg-drop / crumple-zone design (HS-PS2-3) |
| 14–16 | 5 Work & Energy | Ramp/spring energy lab, roller-coaster design (HS-PS3-3) |
| 17 | Review | Quiz review of most-missed items, cumulative project |
| 18 | Final | Semester exam |

Each unit week pattern: Mon notes + demo · Tue practice · Wed lab · Thu quiz + reteach · Fri problem solving / quiz.
