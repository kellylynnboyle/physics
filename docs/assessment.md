# Assessment criteria & progress tracking

[← Course outline](../README.md)

## Proficiency rubric (every learning objective)

| Level | Name | What it looks like |
|---|---|---|
| 4 | Advanced | Explains and applies the idea in new situations, connects it to other topics, and catches/explains common misconceptions. |
| 3 | Proficient | Solves standard problems correctly with units, diagrams and a clear reasoning chain. This is the goal for every student. |
| 2 | Approaching | Understands the main idea but makes errors in setup, signs, units or algebra; needs scaffolds on multi-step problems. |
| 1 | Beginning | Recalls vocabulary or isolated facts; cannot yet set up or solve a problem independently. |

## Suggested grade weighting

| Category | Weight |
|---|---|
| Unit quizzes & exit tickets (formative) | 15% |
| Problem sets / IXL practice | 15% |
| Labs & lab reports (CER format) | 25% |
| Performance task / engineering design | 10% |
| Unit test (summative) | 35% |
