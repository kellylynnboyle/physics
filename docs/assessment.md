# Learning objectives, assessment criteria, and progress tracking

## 4-point proficiency scale

| Level | Name | Descriptor |
|---|---|---|
| 4 | **Advanced** | Applies concepts to new situations, explains reasoning with multiple representations, identifies and corrects errors. |
| 3 | **Proficient** | Meets the learning goal: correct concepts, setup, and calculations with units; minor slips only. |
| 2 | **Developing** | Partial understanding: correct concepts but setup or calculation errors; needs support with graphs or vectors. |
| 1 | **Beginning** | Major misconceptions; only completes problems with step-by-step guidance. |

## Rubric criteria (score each 1–4)

| Criterion | Looks like |
|---|---|
| **Conceptual understanding** | Explains the physics in words, identifies the correct principle, avoids common misconceptions. |
| **Problem solving** | Lists knowns/unknown, draws a diagram, selects an equation, solves algebraically, includes units and checks reasonableness. |
| **Representations** | Moves between words, diagrams (FBDs, energy bars), graphs, and equations. |
| **Investigation & data (SEP)** | Collects data, graphs it, interprets slope/area, evaluates error, and uses evidence to support a claim. |
| **Communication (CER)** | Writes a Claim–Evidence–Reasoning response using correct vocabulary. |

## Mastery requirements (per unit)

- Unit quiz: 80% or higher (retakes allowed; quiz bank is randomized).
- Cornell notes completed with cues, notes, and a 3–4 sentence summary.
- At least one lab report scored 3 or higher on the 4-point rubric.
- Practice problem set: 5 of 6 correct with work shown.
- Performance task for the standard (see below) scored 3 or higher.

## Suggested grade weighting

| Category | Weight |
|---|---|
| Unit quizzes and practice | 25% |
| Labs and investigations | 25% |
| Performance tasks / projects | 20% |
| Cornell notes and homework | 10% |
| Unit tests | 20% |

## Performance tasks

- **Unit 1 Kinematics** (HS-PS2-1): Prediction lab: use a v-t graph from a motion detector to predict stopping distance, then verify.
- **Unit 2 Projectile Motion** (HS-PS2-1): Launch challenge: hit a target landing spot using only measured v₀ and calculations.
- **Unit 3 Newton's Laws** (HS-PS2-1): HS-PS2-1 lab report: analyze a vs. F and a vs. m data, write a CER supporting ΣF = ma.
- **Unit 4 Momentum** (HS-PS2-2, HS-PS2-3): HS-PS2-3 engineering design: build and refine a device to protect an egg or sensor in a collision, with F-t evidence.
- **Unit 5 Work & Energy** (HS-PS3-1, HS-PS3-2, HS-PS3-3): HS-PS3-1/3 model and device: spreadsheet energy model plus a device converting energy, with efficiency analysis.

## Instructor notes

- Use the quiz bank as a pre-assessment, then re-use after instruction to show growth.
- Each quiz item is tagged with the misconception it targets; use the 'Most missed' summary in the site to plan reteaching.
- Allow quiz retakes: the site shuffles answer order each attempt.
- Quiz item difficulty is based on commonly documented misconceptions; replace with your own class data when you have it.
