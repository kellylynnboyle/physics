# Assessment & Progress Tracking

## Mastery levels (used on every unit rubric)

| Level | Label | Meaning |
|-------|-------|---------|
| 4 | Mastery | Solves novel multi-step problems, explains reasoning, spots errors |
| 3 | Proficient | Solves standard problems correctly with units and a labeled diagram |
| 2 | Developing | Right idea, but errors in setup, signs, or units |
| 1 | Beginning | Needs support to start; confuses key quantities |

Proficiency target: **3 or higher on every learning objective**.

## Suggested weighting (adjust to your syllabus)

| Category | Weight | Examples |
|----------|--------|----------|
| Unit tests / performance tasks | 40% | End-of-unit test, design challenge |
| Labs & investigations | 25% | Lab report using CER (claim–evidence–reasoning) |
| Practice & Cornell notes | 15% | Notes check, IXL/practice sets |
| Quizzes (interactive + paper) | 15% | `quiz/index.html` unit quiz, exit tickets |
| Participation / reflection | 5% | Error analysis, corrections |

## Evidence-to-objective rule

Each learning objective (LO) is tracked with at least **three pieces of evidence**:
one quiz item, one problem set item, and one lab/performance observation.
Report the most recent consistent level, not the average.

## Quiz scoring guide

| Score | Interpretation |
|-------|----------------|
| 90–100% | Ready for test; extend with challenge problems |
| 80–89% | Proficient; review the missed items |
| 60–79% | Developing; redo Cornell notes cue column, retake quiz |
| < 60% | Meet with instructor; re-watch the concept resources |

## Lab report rubric (CER)

| Criterion | 4 | 3 | 2 | 1 |
|-----------|---|---|---|---|
| Claim | Precise, testable | Clear | Vague | Missing |
| Evidence | Data table + graph, labeled with units and uncertainty | Data + graph | Partial data | None |
| Reasoning | Links data to physics law quantitatively | Links to law qualitatively | Restates data | None |
| Sources of error | Specific, with effect on result | Specific | Generic ("human error") | None |
