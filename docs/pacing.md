# Suggested Pacing — Semester 1 (≈ 18 weeks; adjust to your calendar)

| Weeks | Unit | Key lab / activity | Assessment |
|---|---|---|---|
| 1–4 | 1. Kinematics | Constant-velocity buggy; ramp acceleration with motion sensor or video analysis | Unit 1 test + graph-interpretation task |
| 5–6 | 2. Projectile Motion | Horizontal launch range prediction ("hit the target") | Unit 2 test + lab report |
| 7–10 | 3. Newton's Laws | Atwood machine / cart-and-hanging-mass: F vs a; friction coefficient lab | Unit 3 test + CER on HS-PS2-1 data |
| 11–13 | 4. Momentum | Collision carts; egg-drop / crumple-zone design (HS-PS2-3) | Unit 4 test + design review |
| 14–16 | 5. Work & Energy | Energy skate park model; pendulum/ramp energy transformations | Unit 5 test |
| 17 | Capstone | Engineering challenge: build a device converting energy under constraints (HS-PS3-3), e.g. rubber-band or gravity-powered vehicle | Design presentation + rubric |
| 18 | Review / final | Quiz bank (`quizzes/`), spiral review of all five units | Semester final |

Build-in: one **quiz + reteach** day at the end of each unit using the "most-missed" results from `quizzes/index.html`.
