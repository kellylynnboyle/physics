## Notes page

| Cues | Notes |
|---|---|
| Core idea of projectile motion | Horizontal and vertical motion happen **independently** and **simultaneously**. They only share one variable: time, t. |
| How to start every problem | Break v_i into components: v_ix = v_i cos(θ), v_iy = v_i sin(θ). |
| Horizontal motion equations | a_x = 0 (constant velocity). x = v_ix t. v_x never changes during flight. |
| Vertical motion equations | a_y = −g (constant). v_y = v_iy − gt. y = v_iy t − ½gt². Same free-fall equations as Unit 1, just applied to y. |
| What happens at max height? | v_y = 0 momentarily. v_x is unchanged — the object is still moving horizontally at full speed. Velocity is NOT zero overall (unless launched straight up). |
| Time of flight (level ground) | t = (2 v_i sin θ) / g — derived by setting y = 0 and solving for the nonzero root. |
| Max height formula | h_max = (v_i² sin²θ) / (2g) |
| Range formula (level ground only) | R = (v_i² sin 2θ) / g |
| Why do complementary angles give equal range? | sin(2θ) = sin(180° − 2θ), so e.g. 30° and 60° (which sum to 90°) produce the same sin(2θ) value and thus the same range. |
| Launch/landing at different heights | The level-ground formulas do NOT apply. Instead, solve y(t) = y_i + v_iy t − ½gt² = y_final as a quadratic for t, then use that t in x = v_ix t. |
| Common error to avoid | Do not reuse the same v_i in both x and y equations without applying cos/sin — this is the single most common projectile-motion mistake. |

*Reference summary: Projectile motion combines constant-velocity horizontal
motion with constant-acceleration (free-fall) vertical motion, connected
only through time. Every problem starts by splitting the initial velocity
into x- and y-components using cosine and sine of the launch angle. At the
peak of the trajectory only the vertical velocity is zero — horizontal
velocity never changes. The level-ground formulas for time of flight, max
height, and range only work when launch and landing heights are equal;
otherwise the vertical motion equation must be solved directly as a
quadratic in time.*
