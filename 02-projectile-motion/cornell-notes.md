# Cornell Notes — Projectile Motion

## Page 1: The Big Idea

| Cue | Notes |
|---|---|
| Core principle | Horizontal and vertical motion are completely independent — they only share the same clock (time t). |
| Why? | Gravity only acts vertically, so there's no horizontal acceleration (ignoring air resistance). Horizontal velocity never changes during flight. |
| Component velocities | vₓ = v·cos(θ), v_y = v·sin(θ), where θ is measured from the horizontal. |
| At the peak of the arc | v_y = 0 (momentarily), but vₓ is unchanged and nonzero. Velocity is NOT zero overall at the top. |

## Page 2: Equations by Axis

| Cue | Notes |
|---|---|
| Horizontal (constant velocity) | x = vₓ · t |
| Vertical (constant acceleration g) | y = v_y·t − ½gt²   and   v_y,final = v_y,0 − gt |
| Horizontal launch special case | v_y,0 = 0, so y = ½gt² — identical to simple free fall |
| Common trap | Never plug the total launch speed v into a single equation — always split into vₓ and v_y first. |

## Page 3: Time of Flight, Height, Range

| Cue | Notes |
|---|---|
| Time of flight (level launch/landing) | t = 2v_y0 / g |
| Max height | h = v_y0² / (2g) |
| Range | R = vₓ · t = v²sin(2θ)/g |
| Optimal angle for max range | 45° — but ONLY when launch height = landing height. Lower landing height → optimal angle < 45°. |
| Complementary angles | θ and (90° − θ) give the same range on level ground. |
