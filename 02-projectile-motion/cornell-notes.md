# Cornell Notes — Projectile Motion

**Topic:** Motion in Two Dimensions Under Gravity | **Date:** ___________ | **Name:** ___________

| Cues / Questions | Notes |
|---|---|
| What's the big idea behind projectile motion? | Horizontal and vertical motion happen **independently** but **simultaneously**, linked only by a shared time, t. Solve two 1D kinematics problems, not one 2D problem. |
| What is the horizontal acceleration? | **Zero.** Gravity pulls straight down, so it never changes horizontal velocity. vₓ is constant for the entire flight (ignoring air resistance). |
| What is the vertical acceleration? | **−g ≈ −9.8 m/s²**, the whole time — same free-fall acceleration as 1D kinematics. |
| How do I break the initial velocity into components? | v₀ₓ = v₀ cos θ (horizontal part) and v₀ᵧ = v₀ sin θ (vertical part), where θ is measured from the horizontal. |
| What's true at the very top of the arc? | **vᵧ = 0** (momentarily), but **vₓ is unchanged** (still moving forward), and **acceleration is still −g** — gravity doesn't pause. |
| When can I use the simple range formula R = (v₀² sin2θ)/g? | **Only** when the launch height equals the landing height. If a ball is kicked off a cliff or up onto a platform, you must solve the vertical motion separately to find total time, then multiply by vₓ. |
| What happens if the projectile is launched purely horizontally? | v₀ᵧ = 0, so the vertical drop is identical to something simply dropped from that height — time to fall only depends on height, not on how fast it's moving forward. |
| Common mistake to avoid | Never plug the resultant (diagonal) velocity into a kinematics equation directly — always use the horizontal or vertical **component**, matched to the horizontal or vertical equation. |
| Is the trajectory shape always the same? | For launch/landing at equal height, the path is a symmetric parabola: time up = time down, and landing speed = launch speed (just flipped in the vertical direction). |

## Summary

Projectile motion is 1D kinematics applied twice — once horizontally
(constant velocity, aₓ = 0) and once vertically (constant acceleration,
a_y = −g) — tied together by the same elapsed time. The starting move on
every problem is decomposing v₀ into v₀ₓ and v₀ᵧ using cosine and sine.
The most common error is treating the two directions as if they affect each
other, or plugging the full launch speed into a single equation instead of
its components. Remember: horizontal velocity never changes during flight;
only vertical velocity does, and it changes at a constant rate of g.
