# Cornell Notes: Projectile Motion

Name: ______________________  Period: ______  Date: ____________

**Learning targets:** I can split a velocity into components. I can solve horizontal-launch and angle-launch problems by treating the two directions separately.

**Essential question:** Why does a ball thrown sideways hit the ground at the same time as a ball that is simply dropped?

**How to use these notes:** cover the Notes column, answer each cue aloud, then check.

| Cues / Questions | Notes |
|---|---|
| **1. Vectors and components** | |
| How do you find the horizontal and vertical parts of a velocity? | For a velocity v at angle θ above the horizontal:<br>**vₓ = v cos θ** (horizontal), **v_y = v sin θ** (vertical).<br>Example: 20 m/s at 30°: vₓ = 20 cos 30° = 17.3 m/s, v_y = 20 sin 30° = 10 m/s. |
| How do you combine components back into one vector? | Magnitude: v = √(vₓ² + v_y²). Direction: θ = tan⁻¹(v_y ÷ vₓ). |
| **2. The big idea** | |
| What is a projectile? | An object moving through the air with **gravity as the only force** on it (air resistance ignored). No "force of the throw" travels with it. |
| What happens to the horizontal velocity during the flight? | It stays **constant**, because there is no horizontal force. aₓ = 0. |
| What happens to the vertical velocity during the flight? | It changes by 9.8 m/s every second, downward. The vertical motion is ordinary **free fall**. |
| What do the horizontal and vertical motions share? | Only the **time**. Find the time from one direction and use it in the other. |
| What are the velocity and acceleration at the top of the path? | Vertical velocity = 0. Horizontal velocity = vₓ, unchanged. So the projectile is still moving. Acceleration = **9.8 m/s² downward**, the same as everywhere else. |
| **3. Horizontal launch** | |
| A ball leaves a 1.25 m table at 4 m/s. Where does it land? (Use g = 10 m/s².) | Vertical: v₀y = 0, Δy = 1.25 m. Δy = ½gt² → t = √(2 × 1.25 ÷ 10) = **0.5 s**.<br>Horizontal: Δx = vₓt = 4 × 0.5 = **2.0 m** from the table.<br>Sense check: a faster launch would not change the 0.5 s, only the distance. |
| Why do a dropped ball and a horizontally launched ball land together? | Both start with zero vertical velocity and fall the same height with the same acceleration. Horizontal speed has no effect on fall time. |
| **4. Launch at an angle** | |
| What are the steps for an angle-launch problem? | 1. Find vₓ and v₀y.<br>2. Use vertical motion to get time (time up = v₀y ÷ g; total time on level ground = 2 × time up).<br>3. Maximum height = v₀y² ÷ (2g).<br>4. Range = vₓ × total time. |
| Which launch angle gives the greatest range on level ground? | **45°**. Angles that add to 90° (30° and 60°, 20° and 70°) give equal ranges. The steeper one goes higher and stays in the air longer. |
| How does the landing speed compare with the launch speed? | On level ground with no air resistance they are **equal**. The vertical velocity returns with the same size and opposite direction. |
| **5. Labs and measurement** | |
| In the marble launch lab, how do you predict the landing spot? | Measure the table height to get the fall time, t = √(2h ÷ g). Measure the launch speed on the tabletop (distance ÷ time). Predicted range = speed × t. |

**Memory tricks**

- SOH CAH TOA for components: cosine goes with the side next to the angle.
- "Horizontal: constant velocity. Vertical: free fall. Time is the bridge."
- Make two columns of knowns, one labeled x and one labeled y, before doing any math.

**Summary**

A projectile's motion is two simple motions happening at once. Horizontally it moves at constant velocity because nothing pushes it sideways. Vertically it is in free fall with a = 9.8 m/s² downward the entire time, including at the top. The two directions are solved separately and connected by the time in the air.
