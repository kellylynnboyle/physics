## Cue Column | Notes

| Cue Column (questions/keywords) | Notes |
|---|---|
| What is **Newton's 1st Law** (inertia)? | An object at rest stays at rest, and an object in motion stays in motion at constant velocity, **unless acted on by a net (unbalanced) force**. "Inertia" is the tendency to resist a change in motion — more mass means more inertia. |
| What is **Newton's 2nd Law**? | Fₙₑₜ = ma. Net force causes acceleration in the *same direction* as the net force. Rearranged: a = Fₙₑₜ/m — acceleration is directly proportional to net force and inversely proportional to mass. |
| What is **Newton's 3rd Law**? | For every action force, there is a reaction force equal in magnitude and opposite in direction, acting on a **different object**. Table pushes up on book (normal force) exactly as hard as book pushes down on table (weight-transmitted force) — these forces act on two different objects, so they never cancel each other in a single free-body diagram. |
| What's the difference between **mass** and **weight**? | Mass (kg) = amount of matter, doesn't change with location. Weight (N) = force of gravity on an object, W = mg, and DOES change with location (less on the Moon, more on Jupiter). |
| What is a **free-body diagram (FBD)**? | A diagram showing ONLY the forces acting ON one object (not forces it exerts on other things), each drawn as an arrow from the object's center, roughly scaled to relative magnitude. Common forces: weight (always straight down), normal force (perpendicular to contact surface), tension (along a rope/string, pulling), friction (opposes relative motion/tendency to slide), applied force. |
| What is **net force**? | The vector sum of all forces acting on an object. Found by adding force components (often after resolving into x/y using trig, especially on inclines). If net force = 0, the object is in equilibrium (constant velocity, possibly zero). |
| What is **normal force**? | The perpendicular contact force a surface exerts on an object, preventing it from passing through the surface. On a flat, horizontal surface with no other vertical forces, N = mg. On an incline, N = mg cos θ. If there's a vertical applied force, N adjusts to keep the object from accelerating through the surface. |
| What is **friction**, and how is it calculated? | A force opposing relative sliding (kinetic friction, f_k = μₖN) or opposing the *tendency* to slide (static friction, up to a max f_s,max = μₛN). Static friction adjusts itself to match applied force up to that max — it is NOT always equal to μₛN. |
| How do you handle **inclined plane** problems? | Rotate your coordinate axes so x is along the incline and y is perpendicular to it. Then: weight splits into mg sin θ (along incline, pulling the object down the slope) and mg cos θ (into the incline, balanced by normal force). |
| Common trap: are **action-reaction pairs** the same as two forces that balance on one object? | **No.** Action-reaction pairs act on two DIFFERENT objects and are always equal by the 3rd law regardless of motion. Two forces on the SAME object that happen to balance (like weight and normal force on a resting book) are a coincidence of equilibrium, not a 3rd-law pair — they act on the same object and are usually different types of force. |

---

## Summary

Newton's three laws explain *why* objects accelerate (or don't): inertia resists changes in motion (1st law), net force determines the size and direction of acceleration via F = ma (2nd law), and every force has an equal-and-opposite partner acting on a different object (3rd law). The core diagnostic skill is drawing a correct free-body diagram — including only forces acting on the object in question — then summing components to find net force before applying F = ma. Mixing up mass/weight, misidentifying 3rd-law pairs, and treating static friction as a fixed value (rather than a maximum) are the most common errors.
