# Cornell Notes — Projectile Motion

**Topic:** Projectile Motion | **Unit:** 2 | **Course:** 11th Grade Physics

---

## Notes

| Cue / Question | Notes |
|---|---|
| What is a projectile? | Any object launched into the air and moving under gravity alone (no thrust, negligible air resistance). Examples: a thrown ball, a launched arrow, a cannonball. |
| The core idea | Horizontal and vertical motion are **independent** of each other. They only share one variable: time. Solve each direction separately, then link them with `t`. |
| Horizontal motion (x) | No horizontal acceleration (a_x = 0) when air resistance is ignored. Horizontal velocity `v_x` is **constant** throughout the entire flight. Use `x = v_x t`. |
| Vertical motion (y) | Constant acceleration `a_y = -g = -9.8 m/s²`. Use the same kinematic equations as free fall: `v_y = v_{y0} - gt`, `y = v_{y0}t - ½gt²`. |
| Launch at an angle | Break initial velocity into components: `v_x0 = v₀cosθ`, `v_y0 = v₀sinθ`, where θ is measured from the horizontal. |
| At the peak of the trajectory | `v_y = 0`, but `v_x` is unchanged (nonzero) — the object is still moving horizontally at the top. Acceleration is still `-g`, never zero. |
| Time of flight (level ground) | If launched and landing at the same height: `t = 2v_y0 / g`. Time to rise = time to fall **only** when launch height = landing height. |
| Range (level ground) | `R = (v₀² sin2θ) / g`. Maximum range occurs at **θ = 45°** on level ground (no air resistance). |
| Maximum height | `H = v_y0² / (2g)`, measured from launch height. |
| Trajectory shape | The path is a parabola — a direct consequence of constant horizontal velocity + constantly accelerating vertical velocity. |
| Symmetric launch angles | Launch angles θ and (90° − θ) give the **same range** (e.g., 30° and 60°), but different max heights and flight times. The 45° launch gives the single maximum range. |
| Horizontally launched projectiles | If launched horizontally off a height (v_y0 = 0), it still falls with `a_y = -g`. Time to land depends only on the height, not on horizontal speed. |
| Independence of mass | In the absence of air resistance, a projectile's trajectory does **not** depend on its mass — a bowling ball and a tennis ball launched identically follow the same path and land at the same time. |

---

## Summary

Projectile motion is really two separate 1D kinematics problems happening at once: constant-velocity horizontal motion and constant-acceleration (free-fall) vertical motion, connected only by a shared time variable. The biggest conceptual trap is treating the two directions as connected — remember that horizontal velocity never changes and vertical acceleration never becomes zero, not even at the top of the arc. Break the initial velocity into components using sine and cosine before doing anything else.
