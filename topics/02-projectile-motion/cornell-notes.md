# Cornell Notes — Projectile Motion

## Notes

| Cues | Notes |
|---|---|
| What is the core idea behind projectile motion? | Horizontal and vertical motion happen independently and simultaneously; the only thing they share is time. |
| How do you find the horizontal and vertical components of launch velocity? | vₓ = v·cosθ, v_y = v·sinθ, where θ is measured from the horizontal. |
| What is the horizontal acceleration (no air resistance)? | Zero. Horizontal velocity is constant throughout the flight. |
| What is the vertical acceleration? | −g = −9.8 m/s² (same free-fall acceleration as 1D kinematics). |
| Which set of equations do you use for the vertical motion? | The same four kinematic equations from Topic 1, applied only to the y-direction. |
| What determines the total time of flight? | The vertical motion only — solve for when y returns to zero (or the ground) using the vertical equations. |
| Once you know the time of flight, how do you find the range? | Range = vₓ × (time of flight), since horizontal velocity is constant. |
| At what angle is range maximized (level launch and landing)? | 45°. |
| Why do two complementary angles (e.g., 30° and 60°) give the same range? | sin(2θ) is the same for θ and (90°−θ), since sin(2θ) = sin(180°−2θ). |
| For a horizontal launch (launched parallel to the ground from a height h), what is v_y initially? | v_y₀ = 0 — all initial velocity is horizontal. |
| Common setup mistake to avoid | Mixing horizontal and vertical variables into one equation. Keep two completely separate mini-problems, connected only by t. |
