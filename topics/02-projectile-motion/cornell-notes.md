**Essential question:** How can two independent motions be combined to predict where a launched object will land?

| Cue / Question (write after class) | Notes (write during class) |
|---|---|
| What is a projectile? | An object moving only under gravity after launch (we ignore air resistance). Its path is a parabola. |
| Why are x and y independent? | Gravity acts only vertically. Horizontal: a = 0, so vₓ is constant. Vertical: a = −9.8 m/s². Time is the link between the two. |
| How do I split a launch velocity? | vₓ = v cosθ; vᵧ = v sinθ (θ measured from the horizontal). |
| What is special about a horizontal launch? | vᵧ₀ = 0. Fall time from y = ½gt²; then x = vₓt. |
| What happens at the top of the path? | vᵧ = 0, vₓ unchanged, a = 9.8 m/s² down. Speed is not zero. |
| Time of flight on level ground? | t = 2vᵧ₀/g (time up = time down). |
| Max height? | H = vᵧ₀²/(2g). |
| Range? | R = vₓ·t = v² sin(2θ)/g. |
| Which angle gives max range? | 45° on level ground. Complementary angles (30°/60°) give equal range; the steeper one stays up longer. |
| What does air resistance do in real life? | Shortens range, lowers the best angle below 45°, and makes the path asymmetric. |
