# Cornell Notes — Projectile Motion

| Cues / Questions | Notes |
|---|---|
| What is projectile motion? | Motion of an object launched into the air that is acted on only by gravity, moving along a curved (parabolic) path. |
| Why are horizontal and vertical motion treated separately? | They are independent of each other — gravity only pulls straight down, so it never changes the horizontal velocity; each direction can be solved with its own kinematics equations. |
| What happens to horizontal velocity during flight? | It stays constant the entire time (vx = constant) because there is no horizontal acceleration when air resistance is ignored. |
| What happens to vertical velocity during flight? | It behaves like free fall — constantly accelerating downward at g = 9.8 m/s², changing speed and eventually direction. |
| How do you find the velocity components from launch speed v and angle θ? | vx = v·cosθ (horizontal component); vy = v·sinθ (vertical component). |
| Common mistake with vx and vy? | Mixing up sine and cosine — remember cosine goes with the horizontal (adjacent) side, sine goes with the vertical (opposite) side. |
| What is true about velocity at the very top of the arc? | Only the vertical velocity (vy) is zero at that instant — horizontal velocity (vx) is unchanged and still moving forward. |
| How do you find time of flight (equal launch/landing height)? | t = 2vy/g, or t = (2v·sinθ)/g — this is double the time to reach the peak. |
| How do you find maximum height? | h = vy²/(2g) — depends only on the vertical component of the initial velocity. |
| How do you find horizontal range? | R = (v²·sin(2θ))/g — valid only when launch height equals landing height. |
| Which angle gives maximum range? | 45° gives the greatest range for a given launch speed on level ground. |
| Which angle gives maximum height? | 90° (straight up) gives the greatest height, but zero range. |
| What do complementary angles (like 30°/60°) have in common? | They produce the same range, but different max heights and flight times. |
| Is the path up and down symmetric? | Yes — for equal launch/landing heights, time up equals time down, and speed at any height is the same going up and coming down. |
| How does a horizontal launch (θ = 0°) differ? | vy starts at 0, so vx = full launch speed and vy = 0 initially; fall time depends only on launch height, same as a dropped object from that height. |

## Summary

Projectile motion is really just two separate motions happening at the same time: constant-velocity motion horizontally and free-fall motion vertically, and neither one affects the other. To solve any problem, I break the initial velocity into its vx and vy components using cosine and sine, then use vy with the free-fall equations to find time of flight and maximum height, and use vx with time to find range. A big misconception I have to watch for is thinking the projectile "stops" at the top of its arc — really, only the vertical velocity is momentarily zero there, while the horizontal velocity keeps going the whole time. I also need to remember that 45° gives the maximum range but 90° gives the maximum height, and that a heavier object launched horizontally still hits the ground at the same time as one just dropped, because mass doesn't affect the vertical motion. Overall, mastering projectile motion means being comfortable switching between the horizontal and vertical "halves" of the problem and knowing exactly which formula answers which question.
