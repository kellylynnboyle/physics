# Cornell Notes — Projectile Motion

**Name:** __________ **Date:** ______ **Period:** ____ **Essential question:** Why can we treat horizontal and vertical motion separately, and how does that predict where a projectile lands?

| Cue / Questions | Notes |
|---|---|
| What is a projectile? | An object moving under the influence of **gravity only** (ignore air resistance). Path is a **parabola**. |
| Key idea: independence? | Horizontal and vertical motions don't affect each other. **Horizontal:** constant velocity (a = 0). **Vertical:** free fall (a = −9.8 m/s²). **Time** is the only shared quantity. |
| Dropped vs fired horizontally? | Hit the ground at the **same time** (same height, same vertical motion). |
| How do I split a launch velocity? | vₓ = v cosθ · v_y = v sinθ (θ above horizontal). Check calculator is in **degrees**. |
| Horizontal launch steps? | 1) Vertical: v₀y = 0, h = ½gt² → t = √(2h/g). 2) Horizontal: x = vₓt. |
| Angled launch (level ground)? | Time t = 2v sinθ / g · Max height H = (v sinθ)² / 2g · Range R = v² sin2θ / g. |
| What is happening at the top? | v_y = 0, **vₓ unchanged**, **a = 9.8 m/s² down** (not zero!). Speed is minimum there. |
| Best angle for range? | 45° on level ground; θ and 90° − θ give the same range. |
| Symmetry? | Landing speed = launch speed at the same height; time up = time down. |
| Common mistakes? | Using total v in vertical equations · adding a horizontal force · thinking a = 0 at the top · time from the wrong direction. |
