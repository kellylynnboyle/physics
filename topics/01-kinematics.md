# Unit 1 — Kinematics (1-D Motion)
**NGSS:** foundation for HS-PS2-1 · **Pacing:** ~4 weeks

## Learning objectives — "I can…"
- [ ] Distinguish distance vs. displacement and speed vs. velocity
- [ ] Calculate average velocity and acceleration with correct sign and units
- [ ] Read position–time and velocity–time graphs (slope and area meanings)
- [ ] Use the four constant-acceleration equations to solve for any unknown
- [ ] Explain free fall: a = g = 9.8 m/s² downward regardless of mass (ignoring air)
- [ ] Build a motion map / dot diagram from a description

## Key concepts & equations
| Concept | Meaning | Equation / rule |
|---|---|---|
| Displacement Δx | Change in position (vector) | Δx = x_f − x_i |
| Average velocity | Displacement ÷ time | v̄ = Δx / Δt |
| Average speed | Total distance ÷ time (scalar) | s = d / t |
| Acceleration | Rate of velocity change | a = Δv / Δt |
| Velocity–time eq. | | v = v₀ + at |
| Position eq. | | Δx = v₀t + ½at² |
| Timeless eq. | | v² = v₀² + 2aΔx |
| Average-velocity eq. | | Δx = ½(v₀ + v)t |
| Free fall | a = −9.8 m/s² (up positive) | use same equations |
| Graphs | x–t slope = v; v–t slope = a; v–t area = Δx | |

## Cornell notes
| Cue (answer aloud) | Notes |
|---|---|
| What is the difference between distance and displacement? | Distance = path length (scalar, always ≥ 0). Displacement = straight-line change in position with direction (vector). Round trip → displacement 0. |
| Speed vs. velocity? | Speed is scalar; velocity includes direction. Runner on 400 m track, back to start in 80 s: avg speed 5 m/s, avg velocity 0. |
| What does the slope of an x–t graph tell you? | Velocity. Steeper = faster; flat = at rest; negative slope = moving in the negative direction. |
| What do slope and area of a v–t graph mean? | Slope = acceleration. Area between curve and axis = displacement (area below axis is negative). |
| When is acceleration positive/negative? | Sign = direction of Δv, not "speeding up". Speeding up if v and a have the **same** sign; slowing if **opposite** signs. |
| What are v and a at the top of a ball's flight? | v = 0 for an instant, a = 9.8 m/s² downward (still!). |
| Which equation do I pick? | List knowns (v₀, v, a, Δx, t). Choose the equation that has your unknown and omits the one variable you neither know nor want. |
| Do heavy objects fall faster? | No (no air). Same g, so same time. Air resistance is what makes feathers slow. |

**Summary:** Kinematics describes motion without asking why. Position, velocity, and acceleration are linked by slope (x→v→a) and area (a→v→x). With constant acceleration, four equations solve every problem — pick by the known/unknown list, keep signs consistent.

## Worked examples
1. **Car from rest, a = 3 m/s², 4 s.** Δx = ½at² = ½(3)(16) = **24 m**; v = at = 12 m/s. (Common error: 12 × 4 = 48 m uses final speed as if it were constant.)
2. **Braking.** v₀ = 20 m/s, a = −4 m/s², v = 0. v² = v₀² + 2aΔx → 0 = 400 − 8Δx → Δx = **50 m**; t = 5 s.
3. **Dropped stone, 3 s.** v = gt = 9.8×3 = **29.4 m/s** down; Δx = ½(9.8)(9) = **44.1 m**.

## Practice problems (answers in brackets)
1. A cyclist goes 12 m/s east for 30 s then 5 m/s east for 20 s. Find total displacement and average velocity. [460 m; 9.2 m/s]
2. A train slows from 30 m/s to 10 m/s in 8 s. Find a and distance. [−2.5 m/s²; 160 m]
3. A ball is thrown up at 14.7 m/s. Find time to the top and max height. [1.5 s; 11.0 m]
4. Sketch the v–t graph for an object thrown up and caught at the same height. [straight line, slope −9.8, crossing zero at the top]
5. From an x–t graph with points (0 s, 0 m), (4 s, 20 m), (8 s, 20 m), (10 s, 0 m): describe motion and each segment's velocity. [5 m/s; 0; −10 m/s]
6. Draw a motion map for a car speeding up. [dots farther apart each step]

Stopping distances & speed limits (distance grows with v²), traffic-light timing, elevator ride comfort, fitness-tracker speed/pace, sprint start analysis, spacecraft burns.
