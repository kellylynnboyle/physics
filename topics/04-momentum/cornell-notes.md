# Cornell Notes — Momentum

**Name:** __________ **Date:** ______ **Period:** ____ **Essential question:** What stays the same in a collision, and how can we reduce the force on a person in a crash?

| Cue / Questions | Notes |
|---|---|
| What is momentum? | **p = mv** (kg·m/s), a vector in the direction of velocity. "Mass in motion." |
| What is impulse? | **J = F_avg Δt = Δp = m(v_f − v_i)** (N·s). Area under a force–time graph. |
| Why airbags / crumple zones? | Same Δp, **longer Δt → smaller F** (F = Δp/Δt). Reduces injury. |
| Bounce vs stick? | Bouncing back reverses direction: Δp = m(v_f − v_i) = m(−v − v) = **−2mv**; larger impulse than stopping (−mv). |
| Conservation of momentum? | If net external force on the system = 0: **Σp_before = Σp_after**. Choose the system to include all interacting objects. |
| Collision equation? | m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′. Pick a + direction; leftward velocities are negative. |
| Perfectly inelastic? | Objects stick: (m₁ + m₂)v′ = m₁v₁ + m₂v₂. Max KE lost (but p conserved). |
| Elastic? | Both p **and** KE conserved. Equal masses, one at rest: velocities exchange. |
| Explosions / recoil? | Start at rest → total p = 0. m₁v₁ = −m₂v₂ (lighter object moves faster). |
| Is KE conserved? | Only in elastic collisions. Momentum is conserved in **all** isolated collisions. |
| Common mistakes? | Ignoring signs · assuming KE conserved · wrong system · confusing impulse and force · forgetting Δp = 2mv for rebounds. |
