# Cornell Notes — Momentum & Collisions

## Notes

| Cues | Notes |
|---|---|
| Define momentum | p = mv. Vector quantity, units kg·m/s, direction matches velocity's direction. |
| Define impulse | J = FΔt. The effect of a force acting over a time interval; a vector. |
| State the impulse-momentum theorem | J = Δp → FΔt = m(v_f − v_i). Impulse causes a change in momentum. |
| State conservation of momentum | In a system with no external net force, total momentum before = total momentum after: Σp_before = Σp_after. |
| What's conserved in an elastic collision? | Both momentum AND kinetic energy. |
| What's conserved in an inelastic collision? | Only momentum. Kinetic energy is lost (converted to heat, sound, deformation). |
| What defines a "perfectly inelastic" collision? | Objects stick together after colliding and move with one shared final velocity. |
| Why does a longer collision time reduce force? | From FΔt = Δp: since Δp is fixed by the collision itself, increasing Δt (contact time) must decrease F (average force) to keep the product the same. |
| What's the most important setup step before solving a momentum problem? | Pick ONE positive direction for the whole problem and assign correct signs (+/−) to every velocity — including velocities given only as "moving toward" or "opposite direction." |
| Common mistake to avoid | Forgetting to check whether "stuck together" (perfectly inelastic, one final velocity) applies, vs. two separate final velocities (general elastic/inelastic case, needs two equations). |
| Common mistake to avoid #2 | Assuming kinetic energy is conserved by default — it's only true for elastic collisions, and you must specifically check total KE before vs. after to classify a collision. |
