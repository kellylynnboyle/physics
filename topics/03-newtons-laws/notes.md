# Cornell Notes — Newton's Laws of Motion

**Topic:** Newton's Laws (Dynamics) | **Unit:** 3 | **Course:** 11th Grade Physics

---

## Notes

| Cue / Question | Notes |
|---|---|
| Newton's 1st Law (Inertia) | An object at rest stays at rest, and an object in motion stays in motion at constant velocity, **unless acted on by a net external force**. Force is not required to *maintain* motion — only to *change* it. |
| What is inertia? | The tendency of an object to resist a change in its state of motion. Inertia depends only on **mass** — more mass means more resistance to acceleration. |
| Newton's 2nd Law | `F_net = ma`. The net (total, vector-sum) force on an object equals its mass times its acceleration. Acceleration is always in the same direction as the net force. |
| Net force | The vector sum of ALL forces acting on an object. If forces are balanced, `F_net = 0` and acceleration = 0 (object is in equilibrium — at rest or constant velocity). |
| Free body diagrams (FBDs) | A diagram showing only the forces acting **on** one object (not forces it exerts on others). Draw the object as a dot/box, then draw arrows for gravity (weight), normal force, tension, friction, applied force, etc. |
| Weight vs. mass | **Mass** (kg) is the amount of matter — constant everywhere. **Weight** (N) is the force of gravity on that mass: `W = mg`. Weight changes with gravitational field strength (e.g., less on the Moon); mass does not. |
| Normal force | The support force perpendicular to a surface, preventing objects from passing through it. On a flat, horizontal surface with no other vertical forces, `N = mg`. On an incline, `N = mg cosθ`. In an accelerating elevator, N changes. |
| Newton's 3rd Law | For every action force, there is a reaction force equal in magnitude and opposite in direction, acting **on a different object**. Action-reaction pairs never act on the same object, so they never cancel each other out. |
| Common 3rd Law pairs | You push on the ground, the ground pushes back on you (this is what lets you walk). A rocket pushes exhaust gas down; the gas pushes the rocket up. |
| Friction — static | Prevents an object from starting to move; `f_s ≤ μ_s N`. Static friction adjusts up to a maximum value to match the applied force, as long as the object stays at rest. |
| Friction — kinetic | Opposes an object already sliding; `f_k = μ_k N` (a fixed value once moving). Generally `μ_k < μ_s` — it's harder to start sliding than to keep sliding. |
| Equilibrium | An object is in equilibrium when `F_net = 0`. This includes objects at rest **and** objects moving at constant velocity — both have zero acceleration. |
| Inclined planes | Break weight into components parallel (`mg sinθ`) and perpendicular (`mg cosθ`) to the incline surface. Normal force balances only the perpendicular component. |
| Tension | The pulling force transmitted through a string/rope/cable. In an ideal (massless, frictionless-pulley) system, tension is the same throughout a single connected string. |

---

## Summary

Newton's three laws connect force to motion: the 1st law says constant velocity needs no force (only a change in velocity does); the 2nd law quantifies that change as F_net = ma; the 3rd law says forces always come in equal-and-opposite pairs acting on *different* objects. Free body diagrams are the essential tool for organizing every force problem — draw all forces on the object of interest, sum them by component, and apply F_net = ma. The most persistent misconception to unlearn is the Aristotelian idea that motion itself requires a sustaining force.
