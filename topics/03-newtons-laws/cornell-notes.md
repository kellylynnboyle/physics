# Cornell Notes — Newton's Laws

## Notes

| Cues | Notes |
|---|---|
| State Newton's 1st Law | An object's velocity doesn't change unless a net (unbalanced) force acts on it. "Objects resist changes in motion" = inertia. |
| State Newton's 2nd Law | ΣF = ma. Net force causes acceleration, in the same direction as the net force. |
| State Newton's 3rd Law | For every force object A exerts on object B, object B exerts an equal and opposite force on object A. |
| Do third-law pairs cancel out? | No — they act on two *different* objects, so they never appear together in the same ΣF = ma equation. |
| What's the difference between mass and weight? | Mass (kg) = amount of matter, constant everywhere. Weight (N) = force of gravity = mg, changes with local gravity. |
| What forces typically appear in a free-body diagram? | Gravity (mg, down), Normal force (N, perpendicular to surface), Tension (T, along string), Applied force (F), Friction (f, opposing relative motion/tendency). |
| Is normal force always equal to mg? | No — only on a flat surface with no other vertical forces. On an incline, N = mg·cosθ. With an added upward force, N is reduced; with an added downward force, N is increased. |
| How do you handle an incline problem? | Rotate the coordinate axes so x is along the incline and y is perpendicular to it. Decompose gravity: gₓ = g·sinθ (along incline), g_y = g·cosθ (into incline). |
| Static vs. kinetic friction | Static friction (up to μ_s·N) resists the *start* of motion; kinetic friction (μ_k·N) acts once the object is already sliding, and is usually smaller than the maximum static friction. |
| How do you solve a two-object connected system? | Either treat the whole system together (net external force ÷ total mass = shared acceleration) or write ΣF = ma separately for each object and solve simultaneously — both approaches must agree. |
| Common FBD mistake to avoid | Including a force the object exerts on something else (that belongs on the *other* object's diagram), or forgetting a force that's actually present (like friction, when not stated as "frictionless"). |
