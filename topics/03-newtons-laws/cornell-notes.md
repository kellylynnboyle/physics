# Cornell Notes — Newton's Laws

**Name:** __________ **Date:** ______ **Period:** ____ **Essential question:** How do forces change the motion of objects?

| Cue / Questions | Notes |
|---|---|
| What is a force? | A push or pull from one object on another; a **vector** measured in newtons (1 N = 1 kg·m/s²). |
| First law? | An object keeps its velocity (rest or constant velocity) **unless a net force acts**. Net force = 0 ⇔ constant velocity (equilibrium). No force is needed to *keep* something moving. |
| What is inertia / mass? | Inertia = resistance to change in motion. **Mass** (kg) measures inertia; it doesn't change with location. |
| Second law? | **a = F_net / m** (F_net = ma). a is in the direction of the **net** force. Doubling F doubles a; doubling m halves a. |
| Third law? | If A pushes on B, B pushes on A with an **equal and opposite** force. The pair acts on **different objects**, so they never cancel each other. |
| Weight vs mass? | Weight W = mg (a force, N). Mass is not a force. 60 kg: 588 N on Earth, 96 N on the Moon. |
| Normal force? | Contact force perpendicular to the surface. Not always = mg (elevator, incline, extra push). |
| Friction? | Opposes sliding. Static: f ≤ μₛN. Kinetic: f = μₖN. Depends on surfaces and N, not on contact area. |
| Free-body diagram (FBD)? | Dot for the object; arrows for **forces on it only**; label each "type, by what". Then ΣF_x = ma_x, ΣF_y = ma_y. |
| Incline? | Along ramp: mg sinθ. Perpendicular: mg cosθ = N (frictionless, no other forces). a = g sinθ. |
| Elevator? | Accelerating up: N = m(g + a). Accelerating down: N = m(g − a). Apparent weight = N. |
| Terminal velocity? | Air drag grows with speed until drag = weight → F_net = 0 → constant velocity. |
| Common mistakes? | "Force of motion" · pairing weight and normal force · forgetting friction · using mass as weight · mixing up which object a force acts on. |

**FBD practice (draw):** (a) book on table (b) box pushed with friction (c) hanging lamp (d) skydiver at terminal velocity.

**Example:** 20 kg crate at constant speed, μₖ = 0.30: F = f = 0.30 × 20 × 9.8 = **58.8 N**.

**Data analysis note (HS-PS2-1):** graph a vs F_net → straight line, slope = 1/m. Claim: a ∝ F_net and a ∝ 1/m.
