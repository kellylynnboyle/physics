| Cues / Questions | Notes |
|---|---|
| What's the difference between distance and displacement? | Distance = total path length traveled (scalar, always ≥ 0). Displacement = straight-line change from start to end position, with direction (vector, can be negative). A round trip has distance > 0 but displacement = 0. |
| What's the difference between speed and velocity? | Speed = distance / time (scalar). Velocity = displacement / time (vector). Average speed ≠ average velocity when the path isn't straight or one direction. |
| What is acceleration? | Rate of change of velocity: a = Δv / Δt. Vector — can point opposite to velocity (deceleration) or the same direction (speeding up). Units: m/s². |
| What are the 4 kinematic equations, and when is each used? | Used only when acceleration is **constant**. Each equation omits one variable — pick the equation missing the variable you don't know: <br>• `v = v₀ + at` (no x) <br>• `x = x₀ + v₀t + ½at²` (no v) <br>• `v² = v₀² + 2a(x−x₀)` (no t) <br>• `x = x₀ + ½(v₀+v)t` (no a) |
| How do I handle free fall? | Set up = positive (or down = positive, but be consistent). a = -9.8 m/s² (if up is positive). At the peak of an upward toss, v = 0 but a ≠ 0. |
| How do I read motion graphs? | **x–t graph:** slope = velocity; curving line = accelerating. **v–t graph:** slope = acceleration; area under curve = displacement. **a–t graph:** area under curve = change in velocity. |
| What sign convention should I use? | Pick one positive direction *before* starting the problem (usually "right" or "up"). Apply it to every position, velocity, and acceleration value in that problem — don't switch mid-solution. |
| Common trap: is negative acceleration always "slowing down"? | No — only if velocity is positive. If velocity is negative and acceleration is negative, the object is speeding up (in the negative direction). "Speeding up" vs "slowing down" depends on whether v and a have the *same* sign (speeding up) or *opposite* signs (slowing down). |
| Does mass affect free-fall acceleration? | No (ignoring air resistance). A feather and a bowling ball dropped in vacuum hit the ground together — both accelerate at g. |
| Average vs. instantaneous velocity? | Average velocity = total displacement / total time over an interval. Instantaneous velocity = velocity at one specific moment (slope of the tangent line on an x–t graph at that point). |

---

## Summary

Kinematics describes motion using position, velocity, and acceleration, treating displacement/velocity/acceleration as vectors that need a consistent sign convention. The four kinematic equations apply only under **constant acceleration** — identify the unknown variable first, then pick the equation missing it. Graphically, slope and area connect the three motion graphs (x–t → v–t → a–t) to each other. The most common errors come from treating vector quantities as scalars, assuming acceleration is zero when velocity is momentarily zero, and misreading slope vs. area on graphs.
