| Cue / Questions (write these *after* class — then cover the right column and quiz yourself) | Notes |
|---|---|
| What is a reference frame? | Choose an origin and a + direction. Position **x** is measured from the origin. Every sign in the problem depends on this choice. |
| Distance vs displacement? | **Distance** (scalar): total path length. **Displacement** Δx = x_f − x_i (vector): straight-line change in position, with direction. |
| Speed vs velocity? | **Speed** = distance / time (scalar). **Velocity** v = Δx / Δt (vector). Round trip: velocity (avg) = 0, speed ≠ 0. |
| What is acceleration? | a = Δv / Δt (m/s²), a vector. Any change in speed **or direction**. |
| How do I tell speeding up from slowing down? | v and a **same sign** → speeding up. **Opposite** signs → slowing down. |
| What do graphs tell me? | **x–t:** slope = velocity. **v–t:** slope = acceleration; **area = displacement**. **a–t:** area = Δv. Flat v–t line = constant velocity (a = 0). |
| Which equations (constant a)? | v = v₀ + at · Δx = v₀t + ½at² · v² = v₀² + 2aΔx · Δx = ½(v₀ + v)t. List knowns (x, v₀, v, a, t), pick the equation missing the unknown you don't care about. |
| What is free fall? | Only gravity acts. a = −9.8 m/s² (down) for all masses. At the top: v = 0 but a = −9.8. Up and down trips are symmetric. |
| What is a motion map? | Dots at equal time intervals: equal spacing = constant v; growing spacing = speeding up. |
| Common mistakes? | Using d = vt when v is changing · forgetting signs · zero v ≠ zero a · confusing slope with area. |

**Example to copy (show your work):** A car brakes from 20 m/s at −5 m/s². Stopping distance?
Given v₀ = 20, v = 0, a = −5 → Find Δx → v² = v₀² + 2aΔx → 0 = 400 + 2(−5)Δx → **Δx = 40 m**.
