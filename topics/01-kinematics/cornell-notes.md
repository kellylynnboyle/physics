# Cornell Notes — Kinematics

**Topic:** Kinematics (1D Motion) | **Class:** Physics | **Date:** ___________

| Cues / Questions | Notes |
|---|---|
| What's the difference: scalar vs. vector? | Scalar = magnitude only (e.g., 5 m/s speed). Vector = magnitude + direction (e.g., 5 m/s north velocity). |
| Distance vs. displacement? | Distance = total path length traveled (always ≥ 0). Displacement = straight-line change in position, Δx = x_f − x_i (can be negative). Example: walk 4 m east then 3 m west → distance = 7 m, displacement = 1 m east. |
| Average velocity formula? | v_avg = Δx / Δt = (x_f − x_i) / (t_f − t_i). Uses displacement, not distance. |
| Average speed vs. average velocity? | Average speed = total distance / total time (always positive). Average velocity = displacement / time (can be negative or zero even if the object moved). |
| Instantaneous velocity — what is it? | The velocity at one exact instant; equals the slope of the position-time graph at that point (tangent line if curved). |
| Position-time graph: how to read it | Slope = velocity. Flat line = at rest. Straight diagonal = constant velocity. Curved line = changing velocity (acceleration). Steeper slope = faster speed. |
| Acceleration — definition & formula | Rate of change of velocity: a = Δv / Δt = (v_f − v_i) / t. Units: m/s². Can speed up, slow down, or change direction. |
| Velocity-time graph: slope and area | Slope = acceleration. Area under the curve (between line and t-axis) = displacement. Flat line = constant velocity (zero acceleration). |
| Common trap: negative velocity vs. negative acceleration | Negative velocity = moving in the negative direction — NOT automatically "slowing down." Negative acceleration = velocity is becoming more negative (decreasing) — could mean speeding up (if already moving negative) or slowing down (if moving positive). Direction and sign must be checked together. |
| The four kinematic equations (constant a) | 1) v = v₀ + at  2) Δx = v₀t + ½at²  3) v² = v₀² + 2aΔx  4) Δx = ½(v₀ + v)t. Pick the equation missing the variable you don't have. |
| Special case: v₀ = 0 | If starting from rest, v₀ = 0 simplifies equations: v = at, Δx = ½at², v² = 2aΔx. Common mistake: forgetting to drop the v₀ term. |
| Free fall — what stays constant? | Acceleration is always g = 9.8 m/s² downward for any object in free fall (dropped, thrown up, or thrown down), ignoring air resistance — mass doesn't matter. |
| Trap: top of a vertical throw | At the very top of the throw, velocity = 0 m/s, but acceleration is still 9.8 m/s² downward — acceleration is NEVER zero during free fall, even momentarily at the peak. |
| Relative motion | Velocity depends on reference frame. Example: a person walking 1 m/s forward on a train moving 20 m/s has a ground-frame velocity of 21 m/s. |

## Summary

Kinematics describes motion using position, velocity, and acceleration without asking what caused it. The key is knowing where each quantity comes from on a graph: slope of position-time gives velocity, and on a velocity-time graph, slope gives acceleration while area gives displacement. The biggest traps are mixing up distance with displacement, assuming negative velocity means "slowing down," and forgetting that acceleration stays constant (g = 9.8 m/s²) even at the exact top of a thrown object's path where velocity is momentarily zero. The four kinematic equations only work when acceleration is constant, and picking the right one just means identifying which variable is missing. When v₀ = 0, several equations simplify, which is a common place to lose points if you forget to drop that term. Overall, kinematics is really a translation skill — moving fluently between a verbal description, a graph, and an equation for the same motion.
