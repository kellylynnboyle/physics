## Notes

| Cues | Notes |
|---|---|
| What's the difference between distance and displacement? | Distance = total path length (scalar, always positive). Displacement = straight-line change in position (vector, can be negative). |
| What's the difference between speed and velocity? | Speed = distance/time (scalar). Velocity = displacement/time (vector). |
| What does the slope of an x-t graph tell you? | Instantaneous velocity at that point. Steeper = faster. Flat = at rest. Negative slope = moving in negative direction. |
| What does the slope of a v-t graph tell you? | Acceleration. |
| What does the area under a v-t graph tell you? | Displacement over that time interval. |
| Can acceleration be nonzero when velocity is zero? | Yes — e.g., a ball thrown straight up has v = 0 at its peak but a = −g the whole time. |
| Does negative acceleration always mean "slowing down"? | No — it means acceleration points in the negative direction. If velocity is also negative, the object speeds up (in the negative direction). |
| List the four kinematic equations. | v = v₀ + at; Δx = v₀t + ½at²; v² = v₀² + 2aΔx; Δx = ½(v₀+v)t |
| How do you choose which equation to use? | Identify which variable is unknown and which three are known; pick the equation that doesn't require the unknown you don't have. |
| What's the standard value of g near Earth's surface? | 9.8 m/s², directed downward (often written as −9.8 m/s² if up is positive). |
| What assumption do the kinematic equations require? | Constant acceleration. They don't apply if acceleration is changing. |
