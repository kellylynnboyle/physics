# Unit 3 — Newton's Laws of Motion
**NGSS:** HS-PS2-1 · **Pacing:** ~4 weeks

## Learning objectives — "I can…"
- [ ] State and apply the three laws in everyday situations
- [ ] Draw correct free-body diagrams (FBDs)
- [ ] Use ΣF = ma in 1-D and along perpendicular axes
- [ ] Distinguish mass from weight; compute F_g = mg
- [ ] Identify action–reaction pairs (different objects!)
- [ ] Model friction (f_k = μ_k N) and tension problems
- [ ] Analyze data (F vs. a graph) to support F_net = ma

## Key concepts & equations
| Concept | Rule |
|---|---|
| 1st law (inertia) | ΣF = 0 ⇔ constant velocity (including at rest) |
| 2nd law | a = ΣF / m  (ΣF = ma, vector) |
| 3rd law | F_A on B = −F_B on A (same type, equal size, opposite direction, different objects) |
| Weight | F_g = mg (g = 9.8 N/kg); mass is constant everywhere |
| Normal force | Perpendicular to surface; not always equal to weight |
| Kinetic friction | f_k = μ_k N, opposes motion |
| Net force | vector sum; 6 N E + 8 N N → 10 N |

## Cornell notes
| Cue | Notes |
|---|---|
| Does a moving object need a net force to keep moving? | No. Constant velocity means ΣF = 0. Force changes velocity (causes acceleration). |
| How do I draw an FBD? | Dot for the object; draw only forces **on** it (gravity, normal, friction, tension, applied). Label each, length ∝ size. Never draw forces the object exerts. |
| What does ΣF = ma mean for 20 N on a 5 kg object? | a = 4 m/s² in the direction of ΣF. |
| Mass vs. weight? | Mass (kg) = amount of matter, same everywhere. Weight (N) = gravitational pull = mg. 10 kg → 98 N on Earth; still 10 kg on the Moon. |
| Truck hits a fly — which force is bigger? | Equal (3rd law). The fly's acceleration is huge because its mass is small. |
| Is the normal force the 3rd-law partner of weight? | No. They act on the **same** object. Weight's partner: object pulls Earth up. Normal's partner: object pushes down on the table. |
| When does N ≠ mg? | Elevator accelerating up: N > mg (feel heavier). Accelerating down: N < mg. Incline: N = mg cosθ. |
| How does friction work? | Opposes sliding. f_k = μN. Static friction adjusts up to μ_sN. Box: 50 N push, 30 N friction, 20 kg → a = 20/20 = 1 m/s². |
| How do I solve a problem? | FBD → axes → write ΣF each axis → solve a → kinematics if needed → check units & sign. |

**Summary:** Forces are interactions that change velocity. Net force sets acceleration (a = ΣF/m); every force has a partner on the other object. FBDs turn word problems into algebra.

## Worked examples
1. **Pushed box.** m = 20 kg, push 50 N, friction 30 N. ΣF = 20 N → **a = 1 m/s²**.
2. **Elevator.** 60 kg person, a = +2 m/s². N − mg = ma → N = 60(9.8+2) = **708 N** (weight 588 N).
3. **Incline (frictionless), θ = 30°.** a = g sinθ = **4.9 m/s²** down the slope.
4. **Net force.** 6 N east + 8 N north → √(36+64) = **10 N** at 53° N of E.

## Practice problems
1. Find the weight of a 70 kg student. [686 N]
2. A 1200 kg car accelerates 2.5 m/s². Net force? [3000 N]
3. A 4 kg block is pulled by a 12 N rope across a surface with μ_k = 0.2. Acceleration? [(12 − 7.84)/4 ≈ 1.04 m/s²]
4. Draw FBDs: book on table; skydiver at terminal velocity; cart on ramp. [terminal: F_air = mg, ΣF=0]
5. 2 kg and 3 kg blocks connected by a string, pulled 10 N over a frictionless table. a and tension on the 2 kg block? [2 m/s²; 4 N]
6. Name the 3rd-law partner: Earth pulls moon. [moon pulls Earth, equal size]
