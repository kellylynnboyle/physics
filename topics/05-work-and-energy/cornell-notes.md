# Cornell Notes — Work & Energy

**Name:** __________ **Date:** ______ **Period:** ____ **Essential question:** How is energy transferred and transformed, and why is the total always conserved?

| Cue / Questions | Notes |
|---|---|
| What is work? | **W = F d cosθ** (joules, J). Force component **along** the displacement. θ = 90° → W = 0. Opposing force (friction) → W < 0. |
| Does carrying a box sideways do work? | No (on the box): lifting force ⟂ displacement at constant velocity. |
| Kinetic energy? | **KE = ½mv²**. Double v → 4× KE. |
| Gravitational PE? | **PE = mgh** relative to a chosen zero level. Only ΔPE matters. |
| Elastic PE? | **PE = ½kx²** (k = spring constant, x = stretch/compression). |
| Work–energy theorem? | **W_net = ΔKE.** Braking: F·d = ½mv² → doubling speed → 4× stopping distance. |
| Conservation of energy? | Energy is neither created nor destroyed. Closed system: ΔKE + ΔPE + ΔE_thermal = 0. Without friction, KE + PE = constant. |
| Energy bar chart? | Bars for KE, PE, thermal at start and end; total height stays the same. |
| Power? | **P = W/t = Fv** (watts). kWh is **energy**, kW is power. |
| Efficiency? | Useful output ÷ total input × 100%. Missing energy → thermal, dispersed (not destroyed). |
| Energy conversion examples? | Dam: PE → KE → electrical. Coaster: PE ↔ KE. Brakes: KE → thermal. Solar: light → electrical. |
| Common mistakes? | Using W = Fd for angled forces · KE linear in v · treating energy as "used up" · inconsistent zero for PE. |

**Speed from height (frictionless):** mgh = ½mv² → v = √(2gh) — independent of mass and path shape.
*Example:* dropped from 5 m → v = √(2·9.8·5) = **9.9 m/s**.

**Energy bar charts (draw):** ball at top / midway / bottom of a ramp.
