# Assessment Rubric — Mechanics Unit

Use this rubric to track mastery across all five sections. It's designed to work either as a standards-based 1–4 scale or converted to a traditional percentage/letter grade (mapping suggested below).

## Mastery Levels (per learning objective)

| Level | Label | Description |
|---|---|---|
| 4 | **Extending** | Applies the concept to novel, multi-step, or combined-topic problems (e.g., a momentum problem that also requires energy methods); can explain *why*, not just *how*; catches and corrects common misconceptions in others' work. |
| 3 | **Proficient** | Solves standard problems correctly and independently; can explain reasoning in words and with a diagram (FBD, motion graph, etc.); understands units and can sanity-check an answer's order of magnitude. |
| 2 | **Developing** | Solves problems with a formula sheet or scaffolding; makes sign/direction errors or unit errors; can follow a solved example but struggles to start from a blank page. |
| 1 | **Beginning** | Recognizes vocabulary but cannot yet set up or solve a problem independently; confuses core concepts (e.g., velocity vs. acceleration, mass vs. weight). |

**Suggested percentage mapping:** 4 → 90–100%, 3 → 80–89%, 2 → 65–79%, 1 → below 65%.

## Section-by-Section Assessment Criteria

For each of the five sections, mastery is evidenced by:

1. **Conceptual quiz** (`quiz.html`) — score of 90%+ on the interactive quiz, including correct reasoning on the "most missed" flagged questions.
2. **Problem set** — the practice problems in the section README solved with correct setup (equation choice + substitution + units), not just a correct final number.
3. **Explain-it-back** — student can verbally or in writing explain one concept from the section to a peer using the Cornell notes summary as a starting point, without reading it verbatim.
4. **Diagram fluency** — student can draw and correctly label the standard diagram for the topic without prompting:
   - Kinematics → position/velocity/acceleration vs. time graphs
   - Projectile Motion → trajectory with velocity vector components at 3+ points
   - Newton's Laws → free-body diagram (FBD) with all forces labeled
   - Momentum → before/after collision diagram with momentum vectors
   - Work & Energy → energy bar chart (LOL diagram) at 2+ points in a system

## Suggested Weighting (if used for a grade)

| Component | Weight |
|---|---|
| Interactive quizzes (5 sections) | 25% |
| Practice problem sets | 30% |
| Unit test / cumulative assessment | 35% |
| Cornell notes / participation | 10% |

## Cumulative Checkpoint Questions

Instructors: these two questions work well as a final checkpoint because they require *combining* multiple sections — a strong signal of true mastery versus memorization.

1. A ball is thrown horizontally off a cliff. Using kinematics/projectile motion, find its velocity components at impact — then use momentum (if it strikes a stationary object) or energy (if asked for impact speed via energy conservation) to finish the problem.
2. A block slides down a frictionless ramp and collides with a second block at the bottom. Use energy conservation to find the velocity at the bottom of the ramp, then use momentum conservation to analyze the collision.

If a student can chain sections together like this, they've moved from "developing" to "extending" across the whole unit.
