# 11th Grade Physics — Learning Project

A self-contained study project covering the core mechanics topics of a standard
11th-grade (algebra-based) physics course: **Kinematics, Projectile Motion,
Newton's Laws, Momentum, and Work & Energy**.

Each unit below follows the same structure so students and instructors can
navigate it consistently, track mastery, and use it either as a self-study
path or as a supplement to classroom instruction.

## How this project is organized

Every unit folder contains four files:

| File | Purpose |
|---|---|
| `README.md` | Key concepts to master, learning objectives, assessment criteria/rubric, prerequisites |
| `cornell-notes.md` | Cornell-style notes (cue questions ↔ notes) for guided review and self-quizzing |
| `quiz.html` | A self-contained, interactive quiz (open directly in any browser) targeting the questions students most commonly get wrong, with instant feedback and explanations |
| `resources.md` | Curated learning resources, practice problems with answers, and real-world applications |

`quiz.html` files need no server or internet connection — just open the file
in a browser. They score automatically and can be retaken.

## For Instructors: Tracking Progress

Each unit's `README.md` includes a **Learning Objectives** list and an
**Assessment Criteria** rubric that maps directly to it. Suggested ways to
use these for tracking:

- Have students self-check off the project checklist above as they complete
  each artifact per unit.
- Use each unit's assessment rubric as a grading checklist for a short quiz,
  problem set, or lab report on that topic.
- The `quiz.html` "most commonly missed questions" files can double as a
  warm-up/bell-ringer, a review activity before a unit test, or a diagnostic
  pre-test to identify misconceptions early.
- Recommended mastery threshold: 80%+ on each unit quiz before advancing to
  the next unit, since later units (Projectile Motion, Momentum, Work &
  Energy) build directly on Kinematics and Newton's Laws.
