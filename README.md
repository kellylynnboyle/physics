# 11th Grade Physics: Core Mechanics Learning Project

A self-contained study project covering the five foundational units of an 11th-grade
mechanics sequence. Each unit folder contains a study guide (key concepts, Cornell
notes, resources, real-world applications, and assessment criteria) plus a
self-grading interactive quiz built around the questions students miss most often.

## How to use this project

- **Students:** Work through units in order — each builds on the last. Read the
  study guide, fill in / review the Cornell notes, work the practice problems, then
  open `quiz.html` in any browser and aim for the mastery threshold before moving on.
- **Instructors:** Use the learning objectives and assessment criteria in each unit
  as a ready-made rubric. The checklist below can be copied into a gradebook or LMS
  as a tracking sheet.

## Course sequence

| # | Unit | Folder | Builds on |
|---|------|--------|-----------|
| 1 | Kinematics | [`kinematics/`](kinematics/README.md) | Algebra, graphing |
| 2 | Projectile Motion | [`projectile-motion/`](projectile-motion/README.md) | Kinematics (esp. vectors, 1D motion) |
| 3 | Newton's Laws | [`newtons-laws/`](newtons-laws/README.md) | Kinematics, vectors |
| 4 | Momentum | [`momentum/`](momentum/README.md) | Newton's Laws |
| 5 | Work & Energy | [`work-energy/`](work-energy/README.md) | Newton's Laws, some momentum |

Each folder contains:
- `README.md` — key concepts, learning objectives, Cornell notes, practice problems,
  real-world applications, resources, and assessment criteria
- `quiz.html` — interactive, self-grading quiz (open directly in a browser, no
  install needed) focused on the most commonly missed question types for that unit

## Master student checklist

Copy this table per student, or track per class. Check off each box as it's completed.

### Unit 1 — Kinematics
- [ ] Read study guide & completed Cornell notes
- [ ] Can distinguish distance/displacement and speed/velocity on a graph and in words
- [ ] Can solve for any unknown using the 3 constant-acceleration kinematics equations
- [ ] Completed practice problem set
- [ ] Scored ≥ 80% on `kinematics/quiz.html`

### Unit 2 — Projectile Motion
- [ ] Read study guide & completed Cornell notes
- [ ] Can decompose an initial velocity into horizontal/vertical components
- [ ] Can find time of flight, range, and max height for level and non-level launches
- [ ] Completed practice problem set
- [ ] Scored ≥ 80% on `projectile-motion/quiz.html`

### Unit 3 — Newton's Laws
- [ ] Read study guide & completed Cornell notes
- [ ] Can draw a correct free-body diagram for any described scenario
- [ ] Can apply F = ma to systems with friction, inclines, and connected objects
- [ ] Can correctly identify Newton's 3rd law force pairs
- [ ] Completed practice problem set
- [ ] Scored ≥ 80% on `newtons-laws/quiz.html`

### Unit 4 — Momentum
- [ ] Read study guide & completed Cornell notes
- [ ] Can apply conservation of momentum to elastic and inelastic collisions
- [ ] Can compute impulse from a force-time graph or F·Δt
- [ ] Completed practice problem set
- [ ] Scored ≥ 80% on `momentum/quiz.html`

### Unit 5 — Work & Energy
- [ ] Read study guide & completed Cornell notes
- [ ] Can compute work with correct use of the angle between force and displacement
- [ ] Can apply conservation of mechanical energy, identifying when it does/doesn't hold
- [ ] Can apply the work-energy theorem
- [ ] Completed practice problem set
- [ ] Scored ≥ 80% on `work-energy/quiz.html`

## Assessment overview

| Level | Criteria |
|---|---|
| **Beginning** | Recalls vocabulary and formulas but cannot apply them without heavy guidance; struggles to set up problems. |
| **Developing** | Solves standard/textbook problems correctly with a given method; inconsistent on multi-step or conceptual (non-numeric) questions. |
| **Proficient** | Solves multi-step problems independently, chooses the correct principle/equation for a novel scenario, explains reasoning in words and diagrams. |
| **Advanced** | Solves non-routine and combined-topic problems (e.g., projectile + energy), critiques flawed reasoning, connects concepts across units. |

Each unit's `README.md` restates this rubric with unit-specific descriptors.

## General resources (all units)

- [The Physics Classroom](https://www.physicsclassroom.com/) — concept-first tutorials + practice
- [Khan Academy: Physics](https://www.khanacademy.org/science/physics) — video lessons + practice sets with instant feedback
- [PhET Interactive Simulations (University of Colorado Boulder)](https://phet.colorado.edu/en/simulations/filter?subjects=physics&type=html) — free, browser-based simulations for every unit below
- [OpenStax Physics (free textbook, algebra-based)](https://openstax.org/details/books/college-physics-2e) — free PDF/online textbook with worked examples and problem sets
- [CK-12 Physics FlexBook](https://www.ck12.org/physics/) — free, adjustable-level reading with embedded practice
