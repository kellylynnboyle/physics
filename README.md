# 11th Grade Physics — Semester 1 Learning Project

Course model: **CA NGSS Physics & Earth Science**. Semester 1 covers Kinematics, Projectile Motion, Newton's Laws, Momentum, and Work & Energy. Semester 2 (electricity, magnetism, waves, light, plate tectonics, earthquakes, nuclear) will follow the same structure.

## How to use this project
| Who | Start here |
|---|---|
| Students | Open a unit file in `units/`, fill in your own Cornell notes, then take the quiz at `quiz/index.html` |
| Instructors | `STANDARDS.md` (alignment), `ASSESSMENT.md` (rubrics, mastery levels), `TRACKER.md` (class/individual checklist) |

## Every unit file contains
1. Learning objectives ("I can…") and NGSS alignment
2. Key concepts, vocabulary, and equations
3. Cornell notes (cue column / notes column / summary) — students complete the blanks
4. Most-commonly-missed questions and the misconception behind each
5. Practice problems with answers
6. Learning resources
7. Real-world applications and a lab idea
8. Assessment criteria

## Suggested pacing (≈18 weeks)
| Weeks | Unit |
|---|---|
| 1–4 | Kinematics (incl. graph analysis lab) |
| 5–7 | Projectile Motion |
| 8–11 | Newton's Laws |
| 12–14 | Momentum (egg-drop / collision design project) |
| 15–17 | Work & Energy |
| 18 | Semester review and exam |
