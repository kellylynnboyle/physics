# Physics 11 — Semester 1: Mechanics

A learning project for 11th grade Physics, built around the NGSS (Next
Generation Science Standards) for California — see the [CDE NGSS
standards page](https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp).

This repo covers the first-semester mechanics sequence: **Kinematics →
Projectile Motion → Newton's Laws → Momentum → Work & Energy.** (Semester 2 —
electricity, magnetism, waves, light, plate tectonics, earthquakes, and
nuclear physics — is a separate project to build out next.)

## Using the interactive app

`app/index.html` is a single self-contained file — no build step, no
install. Open it directly in any browser (double-click it, or serve the
folder with any static file server). Each student's checklist progress and
quiz scores are saved locally in their own browser.

## Standards alignment

This sequence targets the **HS-PS2 (Motion and Stability: Forces and
Interactions)** and **HS-PS3 (Energy)** NGSS disciplinary core ideas, with
kinematics and projectile motion as the mathematical/graphical foundation
those standards assume. Each unit page lists its specific standard codes.
