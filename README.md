# Physics & Earth Science — Semester 1 Learning Project (Grade 11)

Shareable project outline + checklist for students and instructors.
Course goals come from the California NGSS Physics & Earth Science course model (see [`standards.md`](standards.md)).

## How to use this project
1. Work through the five units in order (checklist below).
2. For each unit: read the unit page → fill in / study the **Cornell notes** → do the **practice problems** → take the **interactive quiz** → self-assess against the **objectives checklist**.
3. Instructors: use [`assessment/rubrics.md`](assessment/rubrics.md) and [`assessment/progress-tracker.md`](assessment/progress-tracker.md).

**Interactive quizzes:** open [`quizzes/index.html`](quizzes/index.html) in any browser (no install, works offline). Questions are the most commonly missed ones per topic; each wrong answer explains the misconception. Missed questions can be re-drilled.

## Each unit page contains
- Learning objectives ("I can…") and NGSS alignment
- Key concepts & equations
- Cornell notes (cue questions ↔ notes, summary)
- Worked examples
- Practice problems with answers
- Learning resources (free, online)
- Real-world applications
- Assessment criteria

## Suggested pacing (≈ 18 weeks)
| Weeks | Unit | Lab ideas |
|---|---|---|
| 1–4 | Kinematics | Constant-velocity buggy; ramp acceleration; free-fall timing |
| 5–7 | Projectile Motion | Launcher range vs. angle; horizontal launch off table |
| 8–11 | Newton's Laws | Atwood/cart + hanging mass (F = ma); friction coefficient |
| 12–14 | Momentum | Collision carts; egg-drop impulse design (HS-PS2-3) |
| 15–17 | Work & Energy | Ramp/PE→KE; spring; energy-conversion device (HS-PS3-3) |
| 18 | Review & semester assessment | |
