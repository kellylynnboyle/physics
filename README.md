# Physics & Earth Science — Semester 1 Learning Project (Grade 11)

A shareable project outline, checklist, and set of study tools for the first-semester mechanics units:
**Kinematics → Projectile Motion → Newton's Laws → Momentum → Work & Energy.**

Course context: lab experience + real-world connections + a theoretical framework, aligned to the
California NGSS Physics & Earth Science course model. (Semester 2 – electricity, magnetism, waves, light,
plate tectonics, earthquakes, nuclear physics – can be added as `topics/06-…` and onward using the same templates.)

## What is in this repo

| Path | For | Contents |
|---|---|---|
| `topics/NN-topic/README.md` | Students + instructors | Objectives, key-concept checklist, resources, practice problems, real-world applications, lab ideas, assessment criteria |
| `topics/NN-topic/cornell-notes.md` | Students | Cornell-format notes (cue column / notes / summary) with fill-in cues |
| `quizzes/index.html` | Students | Interactive quizzes on the most-missed questions for each topic (open in any browser, no install) |
| `quizzes/questions.js` | Instructors | The question bank – edit or add questions here |
| `assessment/rubric.md` | Instructors + students | Mastery scale, scoring criteria, lab-report and problem-solving rubrics |
| `assessment/progress-tracker.md` | Students | Printable per-topic progress checklist |
| `docs/standards.md` | Instructors | NGSS performance expectations and how each topic maps to them |
| `docs/pacing.md` | Instructors | Suggested ~18-week pacing |

## How to use

1. **Students:** work through a topic top to bottom — read the README checklist, fill in the Cornell notes, do the
   practice problems, take the quiz, then tick off the objectives in `assessment/progress-tracker.md`.
2. **Instructors:** use the objectives and rubric to grade; edit `quizzes/questions.js` to tune the question bank;
   use the "most-missed" notes in each topic to plan reteaching.
3. **Quizzes:** open `quizzes/index.html` (double-click, or `python3 -m http.server` in this folder and visit
   `/quizzes/`). Scores are saved in the browser only (no accounts, nothing sent anywhere).

## Conventions used throughout

- Take g = 9.8 m/s² (use 10 m/s² only if your instructor says so). Ignore air resistance unless stated.
- SI units; show units on every answer.
- Problem-solving format: **Given → Find → Diagram → Equation → Substitute (with units) → Answer → Reasonableness check.**

> **Note on standards:** The performance expectations in `docs/standards.md` are summarized from the NGSS HS
> physical-science standards (HS-PS2, HS-PS3) adopted by California. Verify wording against the official page
> (<https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp>) before publishing to a district site.
