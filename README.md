# 11th Grade Physics: Semester 1 Learning Project

Physics & Earth Science course model, aligned to the California NGSS (HS-PS2 Motion & Stability: Forces and Interactions, HS-PS3 Energy). Standards: https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp

Semester 1 covers kinematics, projectile motion, Newton's laws, momentum, and work & energy. Semester 2 (electricity, magnetism, waves, light, plate tectonics, earthquakes, nuclear physics) can be added as new units in the same format.

## How to use this project
| Who | Start here |
|---|---|
| Students | Open a unit in `units/`, fill in the Cornell notes, take the quiz in `quiz/index.html`, tick the objectives |
| Instructors | Use the objectives, assessment criteria, labs, and the tracker below |

**Run the quizzes:** open `quiz/index.html` in any browser (no install). Scores are stored on the student's own device.

## Project structure

## Standards map
| NGSS performance expectation | Unit(s) |
|---|---|
| HS-PS2-1 Analyze data to support Newton's second law (F = ma) | 1, 2, 3 |
| HS-PS2-2 Momentum conservation in a system | 4 |
| HS-PS2-3 Design a device to minimize force in a collision | 4 |
| HS-PS2-4 Gravitational and electrostatic force models | 3 (gravitation); electrostatics in Semester 2 |
| HS-PS3-1 Computational model of energy in a system | 5 |
| HS-PS3-2 Energy as motion and position (fields) | 5 |
| HS-PS3-3 Design a device that converts energy | 5 |
| Science & Engineering Practices: data analysis, math models, designing solutions, argument from evidence | All labs |

Kinematics and projectile motion are not stand-alone NGSS expectations; they supply the math and graph skills needed for HS-PS2-1. Instructors should confirm the final alignment against the CDE page and their district pacing guide.

## Cornell notes format
Each unit file has a two-column cue/notes table plus a summary line. Students: cover the right column, answer each cue from memory, then check. Write the summary yourself at the end of the lesson.
