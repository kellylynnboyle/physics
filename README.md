# 11th Grade Physics — Mechanics Learning Project

A self-contained study package covering the core mechanics units of an 11th
grade (Physics 1 / AP Physics 1 level) course: **Kinematics, Projectile
Motion, Newton's Laws, Momentum, and Work & Energy**.

Each unit folder contains the same four pieces, so students and instructors
can navigate the same way every time:

| File | Purpose |
|---|---|
| `README.md` | Key concepts, learning objectives, resources, practice problems, real-world applications |
| `cornell-notes.md` | Fill-in-ready Cornell notes (cues / notes / summary) for guided note-taking or review |
| `quiz.html` | Self-grading interactive quiz built from the questions students most often miss, with explanations |
| — | Practice problems and answer keys are included directly in each `README.md` |

Start with **[PROJECT-OUTLINE.md](./PROJECT-OUTLINE.md)** — the master
checklist, learning objectives, and assessment rubric for the whole project.

## How to use the quizzes

Each `quiz.html` is a single self-contained file — no server or install
required. Open it directly in any browser (double-click it, or right-click →
"Open with browser"). Answers are graded instantly in-page with explanations,
and a score summary appears at the end. Nothing is uploaded or saved;
retaking a quiz just resets it.
