# 11th Grade Physics — Core Mechanics Learning Project

A self-contained study project covering the five foundational topics of an
introductory 11th-grade mechanics sequence: **Kinematics, Projectile Motion,
Newton's Laws, Momentum, and Work & Energy**. Built for students to work
through independently and for instructors to use as a checklist for
tracking mastery.

## How this project is organized

Each topic has its own folder with three pieces:

| File | Purpose |
|---|---|
| `cornell-notes.md` | Cornell-style notes: learning objectives, cue questions, key concepts, vocabulary, and a summary — meant to be read first or used as a study/review sheet. |
| `practice-and-resources.md` | Worked and unworked practice problems (with answer keys), curated external learning resources, and real-world applications. |
| `quiz.html` | A self-grading interactive quiz focused on the questions students most often get wrong on this topic, with explanations for every answer. Open it directly in any browser — no installation needed. |

## Recommended sequence

The topics are ordered deliberately — each one leans on the last:

1. **Kinematics** — describing motion (position, velocity, acceleration) before explaining *why* it happens.
2. **Projectile Motion** — applies kinematics to two dimensions at once.
3. **Newton's Laws** — introduces force as the cause of acceleration.
4. **Momentum** — a second, often more useful, way to analyze forces over time, especially in collisions.
5. **Work & Energy** — a third analysis tool (scalar, not vector) that solves problems force methods struggle with.

## Suggested workflow per topic (for students)

1. Skim the **learning objectives** at the top of `cornell-notes.md`.
2. Read through the notes, filling in the cue-question column answers from memory before checking.
3. Work the practice problems in `practice-and-resources.md`; check answers only after attempting each one.
4. Take the `quiz.html` — it targets the mistakes students make most often on this topic. Review the explanation for every question, right or wrong.
5. Check off the objective(s) in `PROGRESS_TRACKER.md` and record the quiz score.
6. Explore at least one real-world application and one external resource before moving on.

## For instructors

- `PROGRESS_TRACKER.md` contains the full set of learning objectives per topic, mapped assessment criteria, and a checklist table you can copy per student or per class.
- Each `quiz.html` can be assigned as a low-stakes formative check; scores are shown at the end but nothing is transmitted anywhere — it runs entirely in the browser.
- The "most often missed" questions in each quiz are drawn from well-documented, research-backed physics misconceptions (e.g., the Force Concept Inventory literature for Newton's Laws), not arbitrary trick questions — they're worth discussing as a class even after students answer correctly.
