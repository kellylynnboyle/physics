# Physics & Earth Science: Semester 1 Learning Project (Grade 11)

A shareable project outline for students and instructors covering the first-semester physics topics. The California NGSS performance expectations (HS-PS2 and HS-PS3, Physics & Earth Science course model) are the learning goals.

Standards source: [CDE NGSS for California](https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp)

## How to use this project
- **Students:** Work through each unit in order. For each unit, read the outline, fill in the Cornell notes, take the interactive quiz, do the practice problems and labs, then tick the unit checklist.
- **Instructors:** Use the objectives and four-level criteria to assess, and the tracker in [docs/progress-tracker.md](docs/progress-tracker.md) to record progress.
- **Quiz:** Open `quiz/index.html` in any browser (no install needed). Best scores are saved on that device only.

## Every unit includes
1. **Learning objectives** ("Students will be able to…") with IDs (K1, P1, N1, M1, E1).
2. **Key concepts and equations** and the **most-missed ideas** to confront.
3. **Cornell notes** with cue column, notes column, worked example, sketch area, summary, and an IXL practice plan.
4. **Interactive quiz** of the most often missed questions, with explanations and "common trap" feedback.
5. **Resources, lab ideas, real-world applications, and practice problems with answers.**
6. **Assessment criteria** (four levels) and a **unit checklist**.
