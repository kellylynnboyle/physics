# Physics 11 — Mechanics Learning Project

A self-contained study package covering the core mechanics units of an 11th-grade physics course: **Kinematics**, **Projectile Motion**, **Newton's Laws**, **Momentum**, and **Work & Energy**. It's built for students to study from and for instructors to assign, track, and grade against.

Every unit follows the same structure so students always know where to find what they need, and instructors can swap in their own pacing without changing the format.

## How the Project Is Organized

Each numbered folder below is one unit. Inside every unit folder you'll find exactly three files:

| File | Purpose |
|---|---|
| `README.md` | The unit guide — overview, key concepts, learning objectives, equations, common misconceptions, resources, practice problems with an answer key, real-world applications, and an assessment rubric. |
| `cornell-notes.md` | A Cornell-notes template with the core content already filled into the Cue/Notes table, a written summary, and a blank "Your Turn" section for the student's own synthesis. |
| `quiz.html` | A 10-question interactive quiz, opens directly in any browser (double-click the file — no internet connection or server required). Each question targets one of the most commonly missed ideas in that unit, with instant feedback, an explanation, a running score, and a Restart button. |

## Student Checklist

Copy this checklist per unit (or track it in a spreadsheet/LMS) to monitor progress:

- [ ] Read the unit `README.md` overview and Key Concepts section
- [ ] Fill in the `cornell-notes.md` "Your Turn" summary in your own words
- [ ] Review the Key Equations table until you can state when to use each one without looking
- [ ] Work through all Practice Problems, then check against the Answer Key
- [ ] Open `quiz.html` and score at least 8/10 (retake after reviewing missed explanations)
- [ ] Identify which Common Misconceptions you personally held, and correct them in your notes
- [ ] Connect at least one Real-World Application to something you've seen firsthand
- [ ] Self-rate against the unit's Assessment Criteria rubric (Beginning / Developing / Proficient / Advanced)

## Instructor Notes

- **Assessment criteria** in each unit's README use a shared four-level rubric (Beginning, Developing, Proficient, Advanced) mapped to that unit's learning objectives — use these directly as grading rubrics or adapt the language to your gradebook.
- **Quizzes are diagnostic, not summative** — they're built from the misconceptions students most often carry into an exam, so a low first-attempt score is expected and useful; have students retake after reviewing explanations rather than treating the first score as final.
- **Practice problems** are ordered by difficulty within each unit, so you can assign a subset (e.g., problems 1–4) for homework and reserve the harder ones (5–8) for in-class problem-solving or as exam-style questions.
- **Cornell notes** are intentionally partially filled — the Cue/Notes table gives students the content, but the "Your Turn" synthesis is left blank so it can be collected and graded as a check for understanding.
- All `quiz.html` files are single, dependency-free HTML files (no build step, no internet connection needed), so they work equally well distributed via a shared drive, an LMS file upload, or a classroom of offline laptops.
