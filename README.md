# 11th Grade Physics: Semester 1 Learning Project

California NGSS Physics & Earth Science course model. Semester 1 covers mechanics; Semester 2 (electricity, magnetism, waves, light, plate tectonics, earthquakes, nuclear) is out of scope here.

## How to use this project

| Who | Start here |
|---|---|
| Students | Open a unit, work the checklist top to bottom, then take the quiz |
| Instructors | `standards.md` (alignment), `assessment.md` (rubrics, tracker), each unit's answer keys |

## Project checklist

- [ ] **Unit 1 Kinematics**: [`units/01-kinematics.md`](units/01-kinematics.md)
- [ ] **Unit 2 Projectile Motion**: [`units/02-projectile-motion.md`](units/02-projectile-motion.md)
- [ ] **Unit 3 Newton's Laws**: [`units/03-newtons-laws.md`](units/03-newtons-laws.md)
- [ ] **Unit 4 Momentum**: [`units/04-momentum.md`](units/04-momentum.md)
- [ ] **Unit 5 Work & Energy**: [`units/05-work-energy.md`](units/05-work-energy.md)
- [ ] **Interactive quizzes** (most-missed questions, all five units): open [`quizzes/index.html`](quizzes/index.html) in any browser. No install, works offline.
- [ ] **Assessment & progress tracker**: [`assessment.md`](assessment.md)

## Every unit file contains

1. Learning objectives (checkable "I can" statements, with NGSS link)
2. Key concepts and equations
3. Cornell notes (cue questions / notes / summary)
4. Common misconceptions (these feed the quiz)
5. Practice problems with answers
6. Learning resources
7. Real-world applications and lab ideas
8. Assessment criteria for the unit

## Suggested pacing (about 18 weeks)

| Unit | Weeks |
|---|---|
| Kinematics | 1-4 |
| Projectile Motion | 5-7 |
| Newton's Laws | 8-11 |
| Momentum | 12-14 |
| Work & Energy | 15-18 |

## Notes for the instructor

- `standards.md` was written from the NGSS HS Physical Science performance expectations as I know them. **Verify the wording against https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp** before posting; I could not confirm it live in this run.
- Resource names are well-known, free or widely used sources. Check links and school licensing before sharing.
- All quiz answers and practice-problem answers were computed with g = 9.8 m/s².
