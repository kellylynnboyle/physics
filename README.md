# Physics — 11th Grade Mechanics Learning Project

A self-contained study project covering five core mechanics topics: **Kinematics, Projectile Motion, Newton's Laws, Momentum, and Work & Energy**.

Start here: **[PROJECT_OUTLINE.md](./PROJECT_OUTLINE.md)** — the full checklist, unit-by-unit progress tracker, and rubric shared with students and instructors.

Each topic lives in its own folder under [`topics/`](./topics) with:
- a `README.md` (key concepts, equations, learning objectives, assessment rubric, misconceptions, resources, applications, and practice problems)
- `cornell-notes.md` (ready-to-use Cornell-format study notes)
- `quiz.html` (an offline, interactive quiz targeting the questions students miss most often — just open the file in a browser)
