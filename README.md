# Physics — 11th Grade Mechanics Learning Project

A self-contained learning project covering the five core mechanics topics of an 11th grade (algebra-based) physics course: **Kinematics, Projectile Motion, Newton's Laws, Momentum, and Work & Energy**.

👉 **Start here: [PROJECT_OUTLINE.md](./PROJECT_OUTLINE.md)** — the full project checklist with learning objectives and assessment criteria for every unit.

## What's inside

```
topics/
  01-kinematics/          notes.md · quiz.html · resources.md
  02-projectile-motion/   notes.md · quiz.html · resources.md
  03-newtons-laws/        notes.md · quiz.html · resources.md
  04-momentum/            notes.md · quiz.html · resources.md
  05-work-energy/         notes.md · quiz.html · resources.md
assets/
  quiz.css, quiz.js       shared styling/engine for the interactive quizzes
PROJECT_OUTLINE.md        master checklist, objectives & assessment criteria
```

Each topic folder contains:

- **Cornell notes** (`notes.md`) — key concepts in cue-question/notes/summary format
- **Interactive quiz** (`quiz.html`) — a self-grading quiz of the questions students most often get wrong on that topic, with an explanation and "why this trips people up" note after every answer. Open the file directly in a browser — no setup required.
- **Resources** (`resources.md`) — curated videos, readings, simulations, practice problems, real-world applications, and a skills checklist
