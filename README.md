# 11th Grade Physics: Semester 1 Learning Project

A shareable project outline for students and instructors covering **Kinematics, Projectile Motion, Newton's Laws, Momentum, and Work & Energy**, aligned to California NGSS (Physics & Earth Science course model).

## How to use
- **Students:** work through each unit folder in order. Read the unit README, fill out the Cornell notes, take the interactive quiz, and tick the checklist.
- **Instructors:** see [`docs/standards-and-assessment.md`](docs/standards-and-assessment.md) for NGSS alignment, rubrics, and a progress tracker.
- **Quizzes:** open `quiz/index.html` in any browser (no install, works offline). Scores are saved locally in the browser.

Each unit README contains: learning objectives, key concepts, common misconceptions, resources, practice problems with answers, real-world applications, lab/performance task and assessment criteria.

## Suggested pacing (≈16 weeks)
Kinematics 3 wk · Projectile Motion 2 wk · Newton's Laws 4 wk · Momentum 3 wk · Work & Energy 4 wk (includes review/testing time).

## Success criteria
A student has met a unit when they: (1) complete the Cornell notes, (2) score ≥ 80% on the unit quiz (retries allowed), (3) solve 4 of 6 practice problems with work shown, (4) submit the lab/design task at Level 3 or higher, and (5) reach Level 3 on the unit test. Levels are defined in the docs.
