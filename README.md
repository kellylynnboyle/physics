# Physics 11 — Mechanics Learning Project

A self-contained study package covering the core mechanics unit for 11th grade physics: **Kinematics, Projectile Motion, Newton's Laws, Momentum, and Work & Energy**.

Each topic folder contains the same three pieces:

| File | Purpose |
|---|---|
| `cornell-notes.md` | Cornell-style notes — cue questions, main notes, and a summary — covering the key concepts, equations, and vocabulary for the topic |
| `quiz.html` | A self-grading interactive quiz built from the questions students most often get wrong on this topic. Open the file in any browser — no installation needed. |
| `resources.md` | Curated learning resources, practice problem sets, and real-world applications |

Start with **[PROJECT_OUTLINE.md](./PROJECT_OUTLINE.md)** — the master checklist with learning objectives, assessment criteria, and a suggested pacing guide for the whole unit.

## Structure

```
physics/
├── PROJECT_OUTLINE.md          ← start here
├── 01-kinematics/
├── 02-projectile-motion/
├── 03-newtons-laws/
├── 04-momentum/
└── 05-work-energy/
```

## How to use this project

**Students:** For each topic — read the Cornell notes, fill in the cue-column questions in your own words, work the practice problems in `resources.md`, then take `quiz.html` and review any missed questions before moving on.

**Instructors:** `PROJECT_OUTLINE.md` maps each topic to learning objectives and assessment criteria you can use for grading or progress tracking. The quizzes target the misconceptions students most commonly bring into each topic, so a low score on a specific question is a good signal of *which* misconception to re-teach.
