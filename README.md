# Physics — 11th Grade (CA NGSS Physics & Earth Science)

A learning project covering Semester 1 of an 11th grade physics course: lab experience, real-world connections, and a theoretical framework aligned to California's NGSS standards (https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp).

**Semester 1 units:** Kinematics · Projectile Motion · Newton's Laws · Momentum · Work & Energy
**Semester 2 (not yet built out):** electricity, magnetism, waves, light, plate tectonics, earthquakes, nuclear physics

Start here: **[`PROJECT_OUTLINE.md`](./PROJECT_OUTLINE.md)** — the full project outline, student/instructor checklists, learning objectives, assessment criteria, and pacing guide.

Each unit folder contains Cornell-style notes plus a self-contained interactive quiz targeting the most commonly missed questions on that topic:
