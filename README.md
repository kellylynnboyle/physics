# 11th Grade Physics — Semester Learning Project

A self-contained study project covering the core mechanics topics of a first-year
physics course: **Kinematics → Projectile Motion → Newton's Laws → Momentum →
Work & Energy**. Built for students to work through independently and for
instructors to assign, track, and assess.

## How this project is organized

Each topic has its own folder with three things:

| File | Purpose |
|---|---|
| `README.md` | Key concepts, learning objectives, resources, practice problems, real-world applications, assessment criteria |
| `cornell-notes.md` | A filled-in Cornell notes page (cues / notes / summary) for quick review and copying into a notebook |
| `quiz.html` | A self-grading interactive quiz built from the questions students miss most often, with explanations — open it in any browser, no install needed |

## Topic Sequence

- [ ] **[01 · Kinematics](01-kinematics/README.md)** — describing motion in 1D
- [ ] **[02 · Projectile Motion](02-projectile-motion/README.md)** — motion in 2D under gravity
- [ ] **[03 · Newton's Laws](03-newtons-laws/README.md)** — forces that cause motion
- [ ] **[04 · Momentum](04-momentum/README.md)** — collisions and conservation
- [ ] **[05 · Work & Energy](05-work-energy/README.md)** — an alternative lens on motion

Topics build on each other in this order — kinematics is a prerequisite for
projectile motion; Newton's Laws underpin momentum and energy.

## Project-Wide Learning Objectives

By the end of this unit, students should be able to:

1. Represent motion using words, diagrams, graphs, and equations, and move fluently between them.
2. Apply vector reasoning to separate 2D motion into independent components.
3. Draw correct free-body diagrams and apply Newton's Laws to solve for unknown forces or accelerations.
4. Apply conservation laws (momentum, energy) to analyze interactions between objects.
5. Solve multi-step problems that combine two or more of the above topics (e.g., a projectile that undergoes a collision).
6. Connect each concept to at least one real-world engineering or safety application.

## How to Use the Quizzes

Each `quiz.html` is a stand-alone file — double-click it (or open it in any
browser) to run it locally. No internet connection or server required. Each
quiz targets the misconceptions students most commonly carry into a test on
that topic, not just plug-and-chug calculation. Wrong answers show a short
explanation of the misconception so the miss becomes a learning moment.
