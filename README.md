# 11th Grade Physics & Earth Science: Semester 1 Learning Project

Lab-based course covering core mechanics, aligned to the California NGSS HS Physical Science standards ([CDE NGSS page](https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp)). Share this checklist with students and instructors.

## How to use
1. Each unit folder has an overview (objectives, criteria, problems, resources) and Cornell notes.
2. Open `quiz/index.html` in any browser for interactive quizzes on the most commonly missed questions (no install needed).
3. Track progress with `docs/assessment-and-tracking.md`.
