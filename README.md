# Physics & Earth Science — Semester 1 Learning Project (Grade 11)

Lab-based, standards-aligned course project for the California NGSS Physics & Earth Science course model.
Semester 1 covers mechanics; Semester 2 (electricity, magnetism, waves, light, plate tectonics, earthquakes, nuclear physics) will follow the same structure.

Standards: [CA NGSS](https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp). The performance expectations (PEs) below are the learning goals.

## How to use this project

| Who | Start here |
|---|---|
| Students | Open a unit file, fill in the Cornell notes cues, do the practice problems, then take the interactive quiz. Track progress in [`assessment/progress-tracker.md`](assessment/progress-tracker.md). |
| Instructors | [`assessment/rubrics-and-criteria.md`](assessment/rubrics-and-criteria.md) has mastery levels, lab rubric, and the standards map. |
| Quizzes | Open [`quizzes/index.html`](quizzes/index.html) in any browser (no install). 40 questions built around the most commonly missed ideas, with explanations of the misconception behind each wrong answer. |

Each unit file contains: standards alignment, learning objectives, key concepts and formulas, Cornell notes (cues / notes / summary), common misconceptions, resources, practice problems with answers, real-world applications, a lab idea, and unit assessment criteria.

## Pacing (suggested, ~18 weeks)

| Weeks | Unit | Main NGSS PEs |
|---|---|---|
| 1–3 | 1. Kinematics | HS-PS2-1 (foundation) |
| 4–5 | 2. Projectile Motion | HS-PS2-1 |
| 6–9 | 3. Newton's Laws | HS-PS2-1, HS-PS2-4 |
| 10–12 | 4. Momentum | HS-PS2-2, HS-PS2-3 |
| 13–17 | 5. Work & Energy | HS-PS3-1, HS-PS3-2, HS-PS3-3 |
| 18 | Review and final | all |

Kinematics and projectile motion are not separate PEs; they are the mathematical foundation for HS-PS2-1 (analyze data to support Newton's second law). Engineering practices (HS-ETS1) appear in the momentum and energy design tasks.

## Master checklist

### Unit 1 — Kinematics
- [ ] Cornell notes complete
- [ ] Practice set 1 (≥ 80%)
- [ ] Motion-graph lab (position/velocity/acceleration from a cart or motion sensor)
- [ ] Quiz: Kinematics ≥ 80%
- [ ] Unit objectives self-assessed on tracker

### Unit 2 — Projectile Motion
- [ ] Cornell notes complete
- [ ] Practice set 2 (≥ 80%)
- [ ] Projectile launcher / marble ramp lab
- [ ] Quiz: Projectile Motion ≥ 80%
- [ ] Unit objectives self-assessed

### Unit 3 — Newton's Laws
- [ ] Cornell notes complete
- [ ] Free-body diagram portfolio (6 diagrams)
- [ ] Practice set 3 (≥ 80%)
- [ ] Newton's 2nd law lab (a vs. F and a vs. m graphs)
- [ ] Quiz: Newton's Laws ≥ 80%
- [ ] Unit objectives self-assessed

### Unit 4 — Momentum
- [ ] Cornell notes complete
- [ ] Practice set 4 (≥ 80%)
- [ ] Collision cart lab (conservation of momentum)
- [ ] Egg-drop / crumple-zone design task (HS-PS2-3)
- [ ] Quiz: Momentum ≥ 80%
- [ ] Unit objectives self-assessed

### Unit 5 — Work & Energy
- [ ] Cornell notes complete
- [ ] Practice set 5 (≥ 80%)
- [ ] Energy-conservation lab (ramp / pendulum / spring)
- [ ] Energy bar-chart set
- [ ] Quiz: Work & Energy ≥ 80%
- [ ] Unit objectives self-assessed

### Semester wrap-up
- [ ] Mixed-topic review quiz ("All topics" mode) ≥ 80%
- [ ] Reflection: which misconception was hardest to let go of and why

## Notes on the content

- Use g = 9.8 m/s² (10 m/s² acceptable for estimates) and ignore air resistance unless stated.
- Resource links point to free, well-known sources; check them before assigning in case a page has moved.
- Problems and quiz answers were checked by hand; instructors should still skim before assigning.
