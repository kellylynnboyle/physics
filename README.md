# Physics & Earth Science, Grade 11: Semester 1 Learning Project

Course model: California NGSS **Physics & Earth Science** (lab experience, real-world connections, theoretical framework).
Semester 1 covers kinematics, projectile motion, Newton's Laws, momentum, and work & energy. Semester 2 (electricity, magnetism, waves, light, plate tectonics, earthquakes, nuclear physics) will get its own project folders later.

> **Standards note:** The NGSS performance expectations (PEs) are our learning goals. They are listed in `standards/ngss-alignment.md` in paraphrased form from memory of the CA NGSS HS Physical Science PEs. Check wording and codes against <https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp> before publishing to students (the site was not fetched when this was written).

## How to use this project

| Who | Start here |
|---|---|
| Students | Open a unit folder, read `notes.md` (Cornell notes), then take the quiz in `quizzes/index.html` and tick the checklist below. |
| Instructors | `standards/ngss-alignment.md` (standards map), `assessment/rubrics-and-tracker.md` (criteria and gradebook template), each unit's `unit-plan` section. |

## Project structure

```
README.md                      <- this outline / checklist
standards/ngss-alignment.md    <- NGSS PEs, SEP/DCI/CCC, which unit hits which
units/
  01-kinematics/notes.md
  02-projectile-motion/notes.md
  03-newtons-laws/notes.md
  04-momentum/notes.md
  05-work-and-energy/notes.md
quizzes/index.html             <- interactive "most-missed questions" quizzes (open in any browser)
assessment/rubrics-and-tracker.md
```

Each `notes.md` contains, in order: learning objectives, key concepts, Cornell notes (cue | notes), most-missed questions (misconceptions), practice problems with answers, labs, resources, real-world applications, and assessment criteria.

## Master checklist

Students tick each box as it is completed. Instructors can copy this into the LMS.

### Unit 1: Kinematics
- [ ] Objectives read and self-rated (1-4)
- [ ] Cornell notes completed (cues answered aloud from memory)
- [ ] Interactive quiz: score 80%+ (retake missed questions)
- [ ] Practice set 1 (problems 1-8)
- [ ] Lab: constant velocity + accelerated motion, with graphs
- [ ] Unit test / assessment

### Unit 2: Projectile Motion
- [ ] Objectives read and self-rated
- [ ] Cornell notes completed
- [ ] Interactive quiz: 80%+
- [ ] Practice set 2
- [ ] Lab: predict-then-test launch range
- [ ] Unit test / assessment

### Unit 3: Newton's Laws
- [ ] Objectives read and self-rated
- [ ] Cornell notes completed
- [ ] Interactive quiz: 80%+
- [ ] Practice set 3 (include 3 free-body diagrams)
- [ ] Lab: F = ma with force sensor or Atwood machine
- [ ] Unit test / assessment

### Unit 4: Momentum
- [ ] Objectives read and self-rated
- [ ] Cornell notes completed
- [ ] Interactive quiz: 80%+
- [ ] Practice set 4
- [ ] Lab: collisions; design challenge (NGSS HS-PS2-3)
- [ ] Unit test / assessment

### Unit 5: Work & Energy
- [ ] Objectives read and self-rated
- [ ] Cornell notes completed
- [ ] Interactive quiz: 80%+
- [ ] Practice set 5
- [ ] Lab: energy conservation on a ramp / spring
- [ ] Unit test / assessment

### Semester wrap-up
- [ ] Cumulative review of all five "most missed" quizzes
- [ ] Semester exam
- [ ] Reflection: which standards are still at level 2 or below? Make a plan.
