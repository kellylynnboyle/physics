# physics

An 11th Grade Physics learning project covering Kinematics, Projectile Motion, Newton's Laws, Momentum, and Work & Energy.

See [`physics-11/README.md`](physics-11/README.md) for the full project outline, checklist, learning objectives, and assessment rubric. Each topic folder under `physics-11/` includes concept notes, a Cornell-notes template, and an interactive self-grading quiz (`quiz.html`, open directly in a browser).
