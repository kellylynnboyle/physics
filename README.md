# Physics & Earth Science — 11th Grade

A learning project for an 11th grade Physics & Earth Science course, aligned to
California's NGSS high school physical science standards
([CDE NGSS page](https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp)).

- **Semester 1 (this repo):** Kinematics, Projectile Motion, Newton's Laws,
  Momentum, Work & Energy.
- **Semester 2 (future):** Electricity, Magnetism, Waves, Light, Plate Tectonics,
  Earthquakes, Nuclear Physics.

## Start here

- **[PROJECT_OUTLINE.md](PROJECT_OUTLINE.md)** — the master checklist: unit
  sequence, standards map, learning objectives, and assessment rubric.
- **[units/](units/)** — one folder per topic, each with:
  - `README.md` — key concepts, Cornell notes, learning resources, practice
    problems, real-world applications, objectives, and assessment criteria
  - `quiz.html` — an interactive, self-grading quiz built from the questions
    students most often miss on that topic (open directly in any browser)

## For instructors

Everything here is meant to be shared as-is with students, or copied into an
LMS. The `PROJECT_OUTLINE.md` checklist doubles as a syllabus and a
gradebook template. Each unit's quiz works offline and stores best scores
only in the student's own browser (no server or account needed).
