# Physics — Semester 1 Mechanics Learning Project

11th-grade physics (California NGSS Physics & Earth Science model): Kinematics, Projectile Motion, Newton's Laws, Momentum, Work & Energy.

- `PROJECT_OUTLINE.md` — printable outline/checklist: objectives, key concepts, Cornell notes, quizzes, practice, resources, real-world uses, assessment.
- `site/` — interactive version. Open `site/index.html` in a browser (no build step). Includes Cornell notes, shuffled quizzes on most-missed questions with explanations, and a progress tracker saved in the browser.
- Content lives in `site/data.js`; edit it there and regenerate the outline if needed.

Semester 2 topics (electricity, magnetism, waves, light, plate tectonics, earthquakes, nuclear physics) can be added as new entries in `site/data.js`.
