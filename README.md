# 11th Grade Physics & Earth Science – Semester 1 Learning Project

Lab-based physics course aligned to the California NGSS (Physics & Earth Science course model).
Semester 1 covers mechanics; Semester 2 (electricity, magnetism, waves, light, plate tectonics,
earthquakes, nuclear physics) will be added as separate units.

Standards source: <https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp>

Each topic file contains, in order: learning objectives → key concepts → Cornell notes (cue questions / notes)
→ resources → practice problems with answers → real-world applications → lab ideas → completion checklist.

## How to use

**Students:** work a unit top to bottom. Cover the Notes column of the Cornell table and answer each cue aloud,
then take that unit's quiz, then do the practice problems. Tick the checklist at the end of each file.
Re-take missed quiz questions the next day and again a few days later.

**Instructors:** use the objectives and rubric in `standards-and-assessment.md` for grading and the tracker
to record mastery per objective.

## Notes and caveats

- Cornell notes are written from standard physics content, not from your class slides/handouts. Compare them with what
  your teacher posted and adjust vocabulary to match.
- Practice-problem answers were recomputed with g = 9.8 m/s². Use g = 10 m/s² only if your class does.
- Practice-site skill codes (IXL etc.) are intentionally not listed; codes change and were not verified.
  Search the site by topic name instead.
