# 11th Grade Physics — Semester Learning Project

A self-contained study project covering five core mechanics topics for 11th grade physics. Each topic folder contains everything a student needs to learn the material and everything an instructor needs to track mastery: key concepts, learning objectives, Cornell notes, a "most-missed questions" quiz, practice problems, real-world applications, and assessment criteria.

## How to use this project

- **Students:** Work through each topic folder in order. Read the concept overview first, then fill in / review the Cornell notes, then take the quiz *before* looking at the answers — the quiz targets the mistakes students make most often, so getting one wrong is exactly the point of taking it early. Finish with the practice problems.
- **Instructors:** [`PROJECT_OUTLINE.md`](./PROJECT_OUTLINE.md) is the master checklist — pacing, learning objectives, and assessment criteria for the whole unit in one place. Use it to plan lessons, generate rubrics, or track a class's progress topic by topic.

## Prerequisites

Algebra I & II (solving systems of equations, quadratics), basic trigonometry (SOH-CAH-TOA, vector components), and comfort with units and significant figures.
