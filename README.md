# 11th Grade Physics: Semester 1 Learning Project

A shareable project outline for an 11th-grade Physics & Earth Science course (California NGSS). This repository covers **Semester 1: Kinematics, Projectile Motion, Newton's Laws, Momentum, and Work & Energy**. Semester 2 (electricity, magnetism, waves, light, plate tectonics, earthquakes, nuclear physics) will follow the same structure.

## How to use this project

- **Students:** work through each unit file top to bottom (objectives → Cornell notes → quiz → practice → lab → checklist), then track your levels in [docs/assessment-and-progress.md](docs/assessment-and-progress.md).
- **Instructors:** start with [docs/standards-alignment.md](docs/standards-alignment.md) for the NGSS mapping, then use each unit's assessment criteria and the shared rubric.
- **Quizzes:** open `quiz/index.html` in any browser (no install or server needed).

## Notes on accuracy and scope

- Numbers use g = 9.8 m/s² and ignore air resistance unless stated. Every worked answer in the unit files and the quiz was checked by hand.
- Resource entries point to well-known sites by name and topic rather than deep links, since deep links change. Search the named tutorial or simulation on the site.
- The quiz is formative practice. Official mastery levels come from the instructor's assessments.
