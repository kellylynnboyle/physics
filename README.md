# 11th Grade Physics: Semester 1 Learning Project

Kinematics · Projectile Motion · Newton's Laws · Momentum · Work & Energy
Aligned to the California NGSS (HS Physics & Earth Science course model). See [`docs/standards-and-assessment.md`](docs/standards-and-assessment.md).

## How to use
- **Students:** Work through a topic file top to bottom, fill in your own Cornell notes, take the quiz, then do the practice problems.
- **Instructors:** Use the objectives, rubrics, and pacing in `docs/`; adapt freely.
- **Quizzes:** Open `quiz/index.html` in any browser (no install). To host, serve the repo with GitHub Pages or any static host.
