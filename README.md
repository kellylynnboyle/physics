# 11th Grade Physics — Semester Learning Project

A self-contained study package covering five core mechanics topics. Each unit folder contains the same four pieces, so students and instructors always know where to look:

| File | Purpose |
|---|---|
| `README.md` | Key concepts, learning objectives, assessment criteria, resources, practice problems, real-world applications |
| `cornell-notes.md` | Fillable Cornell-notes template pre-loaded with cues and a completed example |
| `quiz.html` | Self-contained interactive quiz (open directly in any browser, no install) targeting the questions students miss most often |
| — | Scores are shown instantly in-browser; no data leaves the device |

## Units

| # | Unit | Folder |
|---|---|---|
| 1 | Kinematics | [`01-kinematics/`](01-kinematics/README.md) |
| 2 | Projectile Motion | [`02-projectile-motion/`](02-projectile-motion/README.md) |
| 3 | Newton's Laws | [`03-newtons-laws/`](03-newtons-laws/README.md) |
| 4 | Momentum | [`04-momentum/`](04-momentum/README.md) |
| 5 | Work & Energy | [`05-work-energy/`](05-work-energy/README.md) |

Units build on each other in this order — Kinematics and Projectile Motion establish the description of motion; Newton's Laws explains what causes it; Momentum and Work & Energy give two alternative "accounting" tools (conservation laws) for analyzing the same motion without solving for forces directly.

## How to use this project

**Students:**
1. Read the unit `README.md` first — skim the key concepts and learning objectives so you know the target before you take notes.
2. Fill in `cornell-notes.md` while reading your textbook / watching the linked videos (cue column first, notes column while learning, summary last — see the note-taking guide below).
3. Work the practice problems.
4. Open `quiz.html` in a browser and take the quiz. Anything you miss, re-read that concept's cue in your notes before retaking it.
5. Check off the unit in the checklist below once you've met the "I can..." objectives.

**Instructors:**
- Assessment criteria in each `README.md` map to the objectives, so they can be lifted directly into a rubric or gradebook category.
- The quizzes are diagnostic (misconception-targeted), not exhaustive — pair them with a traditional problem-set test for summative grading.
- All quiz files are static HTML/CSS/JS with no external dependencies or network calls — safe to host on a class site, LMS file upload, or run offline.

## How to use Cornell Notes

Each `cornell-notes.md` follows the classic three-region format:

- **Cue column** — key terms and questions, filled in *before or after* class as prompts (cover the notes and self-quiz from these).
- **Notes column** — the main content, filled in *during* class/reading.
- **Summary** — 2–4 sentences written *after*, in your own words, tying the page together.
