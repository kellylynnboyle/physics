# 11th Grade Physics — Mechanics Learning Project

A self-contained study project covering five core mechanics topics for 11th grade physics: **Kinematics, Projectile Motion, Newton's Laws, Momentum, and Work & Energy**. Built for use by both students (self-study / review) and instructors (unit planning, progress tracking).

Each unit includes Cornell-style notes, a list of the most-often-missed concepts, an interactive self-check quiz, tiered practice problems, curated resources, and real-world applications. Learning objectives and assessment criteria let progress be tracked unit-by-unit.

## How to use this project

- **Students:** Work through each unit in order — read the notes, attempt the practice problems, then take the interactive quiz. Aim for 80%+ on the quiz *on your second attempt* (the first attempt is diagnostic — it's supposed to surface what you don't know yet).
- **Instructors:** Use the Learning Objectives and Assessment Criteria tables in each unit file as a rubric. The "Most Often Missed Concepts" lists are drawn from common student misconceptions and map directly to the interactive quiz questions, so quiz results double as a formative-assessment tool.

## Interactive Quiz

Open `quizzes/interactive-quiz.html` in any browser (no install needed), or use the hosted version: **[Mechanics Diagnostics](https://claude.ai/code/artifact/2c57a0e6-6b27-4f26-89d1-812e1263aae2)**.

It contains a tab per unit — 35 questions total, 7 per unit — each drawn from the "most often missed" concepts identified in that unit's notes, with immediate self-grading and a short explanation for *every* option (right or wrong), so it works as a review tool rather than just a test.

## Cross-Unit Learning Objectives

By the end of this project, students should be able to:

1. Move fluently between graphical, algebraic, and verbal descriptions of motion.
2. Correctly identify which physics principle (kinematics, forces, conservation of momentum, or conservation of energy) is the fastest route to solving a given problem — many problems can be solved multiple ways, and choosing well is itself a skill.
3. Draw correct free-body diagrams and use them as the starting point for force problems.
4. Apply conservation laws (momentum, energy) confidently, including cases with friction/non-conservative forces.
5. Connect each topic to at least one real-world engineering or scientific application.

## Overall Assessment Rubric

| Component | Weight (suggested) | What it measures |
|---|---|---|
| Interactive quizzes (5 units) | 20% | Recall and recognition of commonly-confused concepts |
| Practice problem sets | 20% | Procedural fluency (basic → challenge tiers) |
| Labs (5 units) | 25% | Applying concepts to real/simulated data, connecting theory to measurement |
| Unit tests (5 units) | 35% | Full problem-solving under test conditions, including multi-concept problems |

**Suggested pacing:** ~1.5–2 weeks per unit (including lab and test day) for a ~8–10 week mechanics sequence.
