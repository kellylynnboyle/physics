# 11th Grade Physics — Mechanics Learning Project

A self-contained study package covering the core mechanics unit for 11th grade physics: **Kinematics, Projectile Motion, Newton's Laws, Momentum, and Work & Energy**. Built for both students (self-study, review, exam prep) and instructors (pacing guide, assessment bank).

Each section follows the same four-part structure:

| File | Purpose |
|---|---|
| `README.md` | Key concepts, learning objectives, resources, practice problems, real-world applications |
| `cornell-notes.md` | Pre-built Cornell notes (cues + notes + summary) ready to study from or use as a fill-in-the-blank worksheet |
| `quiz.html` | Self-grading interactive quiz built from the questions students miss most often, with explanations for every answer |

## How to Use This

**Students:**
1. Read the section `README.md` first — skim the concepts and learning objectives before lecture, review them after.
2. Fill out / re-derive the `cornell-notes.md` in your own words (don't just re-read it — that's the #1 mistake in Cornell note-taking).
3. Work the practice problems *before* opening `quiz.html`.
4. Open `quiz.html` in any browser — no install needed. Retake it until you score 90%+; the explanations are the real teaching tool, not the score.

**Instructors:**
- Section READMEs double as a pacing/lesson-planning outline.
- `quiz.html` files are drawn from historically high-miss-rate conceptual questions (not just plug-and-chug) — useful as bell-ringers, exit tickets, or review-day stations.
- `ASSESSMENT-RUBRIC.md` gives mastery-level criteria you can map to standards-based grading or a traditional rubric.

## Unit Sequence & Progress Tracker

Recommended order — each unit builds on the last (kinematics → projectile motion applies it in 2D → Newton's Laws explains *why* motion changes → momentum and energy give you the two great conservation tools for solving what F=ma can't easily solve alone).

- [ ] **01 — Kinematics** — describing motion: position, velocity, acceleration, the kinematic equations, graphing motion
- [ ] **02 — Projectile Motion** — kinematics in two independent dimensions (horizontal + vertical)
- [ ] **03 — Newton's Laws** — forces, inertia, F = ma, action-reaction, free-body diagrams
- [ ] **04 — Momentum** — impulse, collisions, conservation of momentum
- [ ] **05 — Work & Energy** — work, kinetic/potential energy, conservation of energy, power

Copy the checklist above into your own notes and check off each unit as: (1) concepts read, (2) Cornell notes completed, (3) practice problems attempted, (4) quiz scored 90%+.

## Prerequisites

- Algebra I & II (solving/rearranging equations, systems of equations, quadratics for kinematics)
- Basic trigonometry (SOH-CAH-TOA and the unit circle — required starting in Projectile Motion)
- A scientific calculator

## Units & Conventions Used Throughout

- SI units by default: meters (m), seconds (s), kilograms (kg), Newtons (N), Joules (J), Watts (W)
- Vectors are **bold** or written with an arrow; sign convention (e.g., up/right = positive) is stated at the top of every problem set
- $g = 9.8 \text{ m/s}^2$ (magnitude), directed downward, unless a problem states otherwise
