# 11th Grade Physics — Core Mechanics Learning Project

A self-contained study project covering the five core mechanics topics of a
standard 11th grade (regular or honors-level, pre-AP/AP-adjacent) physics
course:

1. [Kinematics](kinematics/)
2. [Projectile Motion](projectile-motion/)
3. [Newton's Laws](newtons-laws/)
4. [Momentum](momentum/)
5. [Work & Energy](work-energy/)

## How this project is organized

Each topic folder contains the same four documents, so students and
instructors always know where to look:

| File | Purpose |
|---|---|
| `README.md` | Key concepts, learning objectives, and assessment criteria |
| `cornell-notes.md` | Cornell-format notes (cues / notes / summary) ready to print or copy into a notebook |
| `quiz.html` | A self-grading interactive quiz focused on the questions students miss most often, with explanations |
| `resources.md` | Practice problems, real-world applications, and vetted external resources |

The [`PROJECT_OUTLINE.md`](PROJECT_OUTLINE.md) file is the master checklist —
share that one file with students and instructors who want a single
progress-tracking view across all five topics.

## How to use it

**Students:** Work through each topic in order — they build on each other
(kinematics → projectile motion → Newton's Laws → momentum → work & energy).
For each topic: read the `README.md` learning objectives first, fill out
`cornell-notes.md` as you study, work the practice problems in
`resources.md`, then open `quiz.html` in a browser and don't move on until
you can explain *why* each wrong answer is wrong, not just pick the right one.

**Instructors:** `PROJECT_OUTLINE.md` is a ready-to-share checklist with
assessment criteria per topic. Each topic's `README.md` lists explicit,
gradable learning objectives (written as "students will be able to...")
that map directly to the quiz and practice problems.

## Prerequisites

Algebra I and II (solving/rearranging equations, systems of two equations,
basic right-triangle trigonometry — sin/cos/tan). No calculus is required
for this sequence.
