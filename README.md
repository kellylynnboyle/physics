# 11th Grade Physics — Semester 1 Learning Project

Lab experience, real-world connections, and theoretical framework for core mechanics topics, aligned to the [California NGSS (Next Generation Science Standards)](https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp) — the learning goals for this Physics & Earth Science course model.

**Semester 1 (this repo):** Kinematics → Projectile Motion → Newton's Laws → Momentum → Work & Energy
**Semester 2 (not yet built):** Electricity, Magnetism, Waves, Light, Plate Tectonics, Earthquakes, Nuclear Physics

Start here: **[PROJECT-OUTLINE.md](PROJECT-OUTLINE.md)** — the full checklist, pacing guide, and assessment tracker for students and instructors.

Each unit folder contains:
- **`notes.md`** — Cornell-style notes (essential question, cue/notes columns, formulas, vocabulary, summary)
- **`quiz.md`** — an interactive self-check quiz built from the questions students miss most often on this topic, with click-to-reveal answers and explanations

## How to use this project

- **Students:** Read `notes.md` first, work the practice problems, then take `quiz.md` as a self-check before the unit test. Re-take missed questions until you can explain *why* the right answer is right.
- **Instructors:** Use `PROJECT-OUTLINE.md` as the pacing guide and assessment tracker. Each unit's learning objectives map to a suggested formative/summative assessment.
