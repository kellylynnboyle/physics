# Physics 11 — Semester 1 Learning Project

A self-contained learning project for 11th-grade Physics, built around the
**California NGSS Physics & Earth Science course model**
([CDE NGSS standards](https://www.cde.ca.gov/pd/ca/sc/ngssstandards.asp)).

This repository covers **Semester 1: Mechanics** — Kinematics, Projectile
Motion, Newton's Laws, Momentum, and Work & Energy. Each topic folder is a
complete study unit: key concepts, Cornell notes, an interactive quiz built
from the questions students miss most often, resources, practice problems,
real-world applications, and the learning objectives/assessment criteria
used to track progress.

## How to use a topic folder

1. Read the **Key Concepts** section in `notes.md` before class or lab.
2. Fill in the **Cornell Notes** cue column yourself as you take notes — the
   provided cues are starting prompts, not a replacement for your own notes.
3. Work the **practice problems** and check them against the resources listed.
4. Open `quiz.html` in a browser and take the interactive quiz — it targets
   the specific mistakes students make most often on that topic, with
   explanations for every answer.
5. Review the **Learning Objectives** and **Assessment Criteria** to know
   what mastery looks like before the unit test.
